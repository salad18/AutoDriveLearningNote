# 数据集索引

> 自动驾驶感知/规划的核心数据集汇总。

---

## 一、3D 目标检测数据集

### nuScenes

| 项目 | 信息 |
|------|------|
| **全称** | nuScenes Dataset |
| **发布** | 2020, Motional (原 nuTonomy) |
| **传感器** | 6 相机 + 1 LiDAR + 5 Radar + IMU |
| **场景** | 波士顿、新加坡城市道路 |
| **规模** | 1000 场景 × 20 秒, 1.4M 帧 |
| **标注** | 23 类 3D BBox，1.4M 标注框 |
| **链接** | [nuScenes.org](https://www.nuscenes.org/) |

**关键指标**：
- **NDS** (nuScenes Detection Score): 综合检测指标
- **mAP**: 平均精度
- 五个 error metric: ATE, ASE, AOE, AVE, AAE

**nuScenes 是 BEV 感知的 "ImageNet"**，几乎所有 BEV 论文都在上面评测。

### Waymo Open Dataset

| 项目 | 信息 |
|------|------|
| **全称** | Waymo Open Dataset |
| **发布** | 2019-2024, Waymo (Google) |
| **传感器** | 5 LiDAR + 5 Camera (高分辨率) |
| **规模** | 1150 场景 × 20 秒, 12M 标注框 |
| **类别** | 4 类 (Vehicle, Pedestrian, Cyclist, Sign) |

**特点**：
- 传感器质量最高（Waymo 自研 LiDAR）
- 数据量大（是 nuScenes 的 ~10 倍）
- 提供 2D/3D 检测、2D/3D 跟踪、轨迹预测等多任务标注

### KITTI

| 项目 | 信息 |
|------|------|
| **全称** | KITTI Vision Benchmark Suite |
| **发布** | 2012-至今 |
| **传感器** | 2 Camera + 1 Velodyne LiDAR + GPS/IMU |
| **规模** | 7.5K 训练 + 7.5K 测试 |

**经典但老旧**，现在主要用于轻量级验证和传统 3D 检测 baselines。

## 二、BEV / Occupancy 数据集

### Occ3D (NeurIPS 2023)

| 项目 | 信息 |
|------|------|
| **内容** | 基于 nuScenes/Waymo 的 3D 占据标注 |
| **占据尺寸** | nuScenes: 200×200×16, Waymo: 200×200×32 |
| **语义类别** | 17 类 |
| **标注来源** | LiDAR 点云稠密标注 |

**这是 3D 占据预测的事实标准数据集。**

### SemanticKITTI

| 项目 | 信息 |
|------|------|
| **内容** | KITTI + 语义点云标注 |
| **占据尺寸** | 256×256×32 |
| **语义类别** | 20+ 类 |

用于语义场景补全（Semantic Scene Completion）评测。

### OpenOccupancy / SurroundOcc

| 项目 | 信息 |
|------|------|
| **特点** | 通过多种方式生成 pseudo occupancy labels |
| **用途** | 对比不同占据标注方法的影响 |

## 三、端到端驾驶数据集

### nuScenes (用于规划评测)

nuScenes 提供了：
- 2Hz 的未来轨迹真值（用于规划评测）
- 开环评测（L2 Error, Collision Rate）

### CARLA Leaderboard

| 项目 | 信息 |
|------|------|
| **类型** | 仿真环境 + 闭环评测 |
| **任务** | 从 A 到 B 的自动驾驶 |
| **指标** | Driving Score, Route Completion, Infractions |

**闭环评测的金标准**，但 CARLA 的视觉质量与真实世界有差距。

### NAVSIM

新出的端到端评测基准，基于 nuPlan 数据集，支持开环和闭环评测。

## 六、选择指南

```
目标检测入门:     nuScenes → KITTI
BEV 研发:         nuScenes (最标准)
占据网络:         Occ3D-nuScenes
端到端开环评测:    nuScenes (L2 / Collision)
端到端闭环评测:    CARLA Leaderboard
协同感知:         OPV2V / V2V4Real
大模型驾驶:       DriveLM
大算力研究:       Waymo Open Dataset
```
