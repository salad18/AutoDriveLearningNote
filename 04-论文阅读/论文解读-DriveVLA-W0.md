## 核心问题——"监督稀疏"（Supervision Sparsity）

### 为什么智驾的 scaling law 会失效？

```
大模型规律:  数据量 ↑ → 模型性能 ↑（Data Scaling Law）
智驾的现实:  数据量巨大（量产车天天在录）但模型不涨了 → scaling law 失效
根源:        "数据多，但有效监督少"
```

**监督稀疏的三种表现（面试必讲）：**

| 维度 | 说明 |
|------|------|
| **动作标签稀疏** | 海量视频**没有"方向盘/油门"标签**——纯视觉采集（特斯拉式）只有图像，没有动作真值 |
| **推理标签稀疏** | VLA 需要"语言/推理"标注（为什么这么开），人工标注极贵 |
| **场景真值稀疏** | 大部分数据是"正常驾驶"（[[数据闭环总览]] 的 99.9% 平凡数据），corner case 稀有 |

> [!warning] 这个洞察的价值（面试核心谈资）
> 特斯拉有海量车队数据，为什么 FSD 还难？**因为数据 ≠ 监督**——录了 1000 万小时视频，但"每帧该打多少方向"的标签几乎没有。**"数据规模法则"的前提是"监督规模法则"**——监督跟不上，数据再多也不涨。这就是"监督稀疏"问题。

## 方法——世界模型怎么"放大"数据

### 核心思路（一句话）

```
世界模型（[[世界模型]]）学会"驾驶世界的动态"后，可以:
  ① 生成新的驾驶场景（数据增强）
  ② 补全/重建场景（把不完整数据变完整）
  ③ 预测未来状态（提供伪标签/自监督信号）
→ 把"无监督的原始数据"变成"有监督的训练数据"
→ 数据规模法则重新生效（数据放大，监督也放大）
```

### 技术链条

```
海量无监督驾驶视频/场景
        ↓
世界模型（学习环境动态: 场景结构 + 运动 + 物理一致性）
        ↓
生成/重建/补全 → 带"监督信号"的合成场景
        ↓
训练 VLA 智驾模型（[[VLA入门与智驾应用]]）
        ↓
性能提升（scaling law 恢复）
```

> [!note] "W0"的含义（据公开解读）
> "W0"指**零样本/预训练阶段的世界模型**——在真实数据上预训练世界模型，再用于数据生成。**"世界模型先学会世界，再帮主模型造数据"**——两阶段分工（世界模型是"数据工厂"，VLA 是"学生"）。

### 和"数据闭环"的关系（本库联动）

```
传统数据闭环: 采集 → 挖掘 → 标注（人工）→ 训练 → OTA
DriveVLA-W0:  采集 → 世界模型生成 → 自动监督 → 训练 → OTA
             ↑ 把"人工标注"换成"世界模型自动生成监督"
```

> 这正是 [[数据闭环总览]]"生成式数据增强"趋势（未来趋势第 2 条）的落地证明。

## 关键结果与结论

> 具体数值以论文为准（此处为方向性结论，建议精读原文验证）

| 结论 | 说明 |
|------|------|
| **数据规模法则恢复** | 加入世界模型生成数据后，模型性能随"有效数据"规模提升 |
| **监督稀疏缓解** | 无监督视频通过世界模型获得监督信号 |
| **VLA 受益** | 数据饥渴的 VLA 智驾（[[VLA入门与智驾应用]] 挑战 4）获得规模化数据 |

> [!warning] 读结果的批判性视角
> ① **合成数据的分布偏差**：世界模型生成的数据有"模型偏见"（老师会什么生成什么）→ 需要真实数据校准（[[大模型训练技巧进阶]] 的"合成打底+真实兜底"）；② **世界模型本身的质量**：世界模型错，生成的数据就错（级联误差）；③ **评估口径**：要在闭环评测（[[端到端自动驾驶概览]]）里验证，不能只看开环指标。

## 面试/讨论追问

> [!question] Q1：为什么"数据多但模型不涨"？核心概念是什么？
> 提示：监督稀疏。

> [!success]- 参考答案
> 核心概念是**监督稀疏（Supervision Sparsity）**：智驾数据量大（量产车天天录），但"有效监督"稀疏——① 海量视频没有动作标签；② VLA 需要语言/推理标注（贵）；③ 大部分是平凡场景（corner case 稀有）。数据规模法则的前提是"监督规模法则"——监督跟不上，数据再多模型也不涨。

> [!question] Q2：世界模型怎么"放大"数据？和人工标注的区别？
> 提示：自动生成监督。

> [!success]- 参考答案
> 世界模型学会环境动态后，可以生成新场景、补全场景、预测未来——**把"无监督原始数据"变成"带监督信号的训练数据"**（自动生成监督）。和人工标注的区别：① 规模（世界模型无限生成 vs 人工有限）；② 成本（自动 vs 高价）；③ 风险（世界模型有"模型偏见"，生成数据可能带偏差 → 需真实数据校准）。

> [!question] Q3：DriveVLA-W0 有什么局限性？
> 提示：合成偏差/级联误差/评估。

> [!success]- 参考答案
> ① 合成数据分布偏差（世界模型会什么生成什么，可能过拟合合成分布）；② 级联误差（世界模型错→生成数据错→VLA 学错）；③ 评估口径（需闭环验证，开环指标会高估）；④ 世界模型本身训练成本高。解法方向：真实数据校准混合、"合成打底+真实兜底"（[[大模型训练技巧进阶]]）。

> [!question] Q4：这篇论文对"纯视觉路线"（特斯拉）意味着什么？
> 提示：无标签数据利用。

> [!success]- 参考答案
> 纯视觉路线（特斯拉）的最大瓶颈就是"监督稀疏"——海量视频没动作标签（公开解读正是以"解决特斯拉监督稀疏难题"为引子）。DriveVLA-W0 提供了一条路：**用世界模型把无标签视频变成有监督数据**——对纯视觉方案尤其重要（没有 LiDAR 真值辅助监督，更需要自监督/生成式监督）。
