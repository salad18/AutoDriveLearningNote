# LeetCode 刷题规划（100 题分级清单）

> 一句话导读：[[面试准备策略]] 说"算法岗的算法题不是 LeetCode 而是模型推导"——**但这是相对的**。华为/地平线/Momenta 等公司的一面仍会手撕基础算法（数组/链表/树/DP/二分），大厂通用岗和部分面试官也会考。本篇给你：**100 题分级清单 + 30 天刷题计划 + 与模型手撕的配比**，让你在"够用"和"不浪费时间"之间找到平衡。

---

## 🧭 本篇导读

| 项目 | 内容 |
|------|------|
| **这篇学什么** | 为什么智驾算法岗也要刷 LeetCode、100 题分级清单（核心 50 + 进阶 50）、30 天刷题计划、刷题的正确姿势、与 [[手写算法-Python版]] 的配比 |
| **需要的前置知识** | Python 基础（你已有）；数据结构基础（数组/链表/树/图）|
| **学完之后你能** | ① 知道智驾岗技术面会考哪些算法题、考到什么难度；② 用 30 天覆盖高频 100 题；③ 把模型手撕和 LeetCode 的时间分配好 |
| **预计阅读时间** | 20 分钟，之后按计划刷题 |

> [!tip] 核心判断：**不要陷入"刷题焦虑"**
> 智驾感知岗的面试重心是**模型推导 + 项目深挖**（[[面试准备策略]] 六节），LeetCode 是"补漏项"不是"主战场"。**100 题（高频核心 50 + 进阶 50）足够**——刷 300 题反而挤占模型学习时间，得不偿失。真遇到 LeetCode 型公司（如华为某些面试官），核心 50 题能撑住大部分场景。

## 一、为什么智驾算法岗也要刷？

| 场景 | 考不考 LeetCode | 对策 |
|------|:--:|------|
| **感知/端到端算法岗**（主流） | 少考或只考简单题 | 核心 50 题打底，重点在模型手撕 |
| **华为/地平线/Momenta 一面** | 考（手撕编码） | 核心 50 + 进阶 50，中等难度 |
| **大厂通用算法岗**（百度/腾讯系） | 考（中等偏上） | 进阶 50 重点覆盖 |
| **外企（英伟达等）** | 考（中等） | 核心 50 + 刷一遍高频 |

> [!note] 一句话
> **面试官考 LeetCode 不是看你会不会做题，是看"代码基本功 + 边界处理 + 沟通"**——写代码时边写边说思路、考虑边界（空输入/越界），比"秒出答案"更重要。

## 四、30 天刷题计划（每天 2-3 题）

| 周 | 重点 | 题量 |
|----|------|------|
| 第 1 周 | 数组 + 链表（题 1-20） | 每天 3 题 |
| 第 2 周 | 二叉树 + 栈/队列（题 21-36） | 每天 2-3 题 |
| 第 3 周 | 二分 + 排序 + DP（题 37-47） | 每天 2 题 |
| 第 4 周 | 图 + 回顾错题 + 进阶选刷 | 每天 2 题 |

**刷题姿势**（比刷题量重要）：
1. **先自己想 10 分钟**，想不出看提示（不是答案），再想 10 分钟；
2. **写出来再优化**——先写暴力解，再优化复杂度；
3. **口述讲一遍**——面试是"边写边说"，刷题时假装在面试；
4. **错题本**——用 [[面试复盘记录]]（待建）记录每题的错误原因；
5. **二刷**：第 4 周只刷错题和核心题，二刷比新题有价值。

## 五、和模型手撕的配比（智驾岗关键）

```
时间分配建议（面试前 8 周）:
  ├── 模型手撕（[[手写算法-Python版]] 6 件套）: 40%  ← 智驾岗核心
  ├── LeetCode（核心 50 题）:                 30%  ← 补漏
  ├── 论文/项目/面试题:                       30%  ← 主战场
```

> [!warning] 常见误区
> 1. **刷题上瘾**——LeetCode 有即时反馈容易上瘾，但智驾岗面试重心不在这，别刷到 300 题还没复习模型；
> 2. **只刷简单题**——面试会考中等难度，核心 50 里中等题占比最高；
> 3. **不写不练只背**——代码要能白板写，光看答案没用；
> 4. **忽视沟通**——"边写边讲"是评分点，闷头敲键盘会被扣分。

## ✅ 自测一下

> [!question] Q：智驾感知岗一面，LeetCode 大概考什么难度？

> [!success]- 参考答案
> 多数考**简单到中等**（两数之和、链表反转、二叉树遍历、滑动窗口），偶尔加一道困难题作为区分（如接雨水）。重点不是题本身，是**边界处理 + 复杂度分析 + 边写边讲**——写完后主动说"O(n) 时间 O(1) 空间，边界情况有…"。
