# 投递定位：数据算法岗 × 算法岗（一稿两投）

> 你的目标就两个：**数据算法岗**（挖掘/自动标注/数据闭环算法）和**算法岗**（感知/端到端）。同一段 ADS 数据闭环经历，**投数据岗讲"效率"，投算法岗讲"涨点"**——这份文档给你两套简历、两份项目卡、两套陈述、一张题分布表。

---

## 〇、一句话区别

| | 数据算法岗 | 算法岗 |
|---|---|---|
| 一句话 | **把数据变成可训练资产** | **把数据变成更强的模型** |
| 你的角色 | 造"弹药"的人 | 用"弹药"打仗的人 |
| 面试官最关心 | 数据效率（挖得准、标得快、迭代快） | 模型效果（涨点、泛化、上车） |
| 同一件事的说法 | "我建了检索，把 bad case 扩成类" | "我用这批数据把该场景 +2.1 点，整体不掉" |

> [!warning] 最常见的错
> 拿数据岗的话术去面算法岗——满口"自动化率/返工率"，面试官会想"那你模型能力呢"。**必须翻译成模型指标。**

| 维度 | 数据算法岗 | 算法岗 |
|------|------------|--------|
| **日常** | 挖掘策略、检索、自动标注、数据配比、质量体系 | 模型结构、训练、蒸馏、部署、评测 |
| **考核** | 挖掘有效率、自动化率、返工率、迭代周期 | mAP/NDS、分场景指标、闭环通过率、延迟 |
| **JD 关键词** | 数据挖掘、自动标注、场景检索、embedding、主动学习、4D 标注、数据闭环、表征模型 | BEV、3D 检测、占据、端到端、VLA、mAP/NDS、TensorRT |
| **面试官构成** | 数据算法 lead + 感知算法（交叉面） | 感知算法 lead + 训练/部署 |
| **代码要求** | Python + SQL/Spark（够用） | Python 手撕 + 模型推导 |
| **加分项** | 大规模检索、4D/OCC 标注、数据引擎 | 论文/竞赛、开源复现、部署经验 |

## 二、同一段经历，两种简历写法

### 数据算法岗版（3 条 bullet）

```
- 搭「离线 teacher 预标注 + 三级置信度 + 轨迹级 4D 校验」流水线：
  自动化率 55%→88%，返工率 35%→9%，单帧标注成本降 X%。
- 建场景 embedding + ANN 检索（IVF-PQ + 精排），把单点 bad case
  扩成批量场景集：挖掘有效率 12%→38%，新场景覆盖簇数 +X/月。
- 建数据版本与血缘（样本→数据集→模型→评测→部署），
  支撑迭代周期 6 周→2 周，模型退化可 1 天内定位到数据版本。
```

### 算法岗版（3 条 bullet）

```
- 针对施工区/非机动车横穿长尾：用检索+主动学习定向补 X 万帧，
  该场景切片 +2.1 点，整体 NDS 不掉（回归门禁 0 退化）。
- 用离线 teacher 蒸馏到车端：同等延迟下 mAP +X；或同精度下延迟 −X ms。
- 建分场景回归门禁（标准/困难/切片/安全/闭环五道），
  把"上线后掉点"提前到发版前拦截，回归通过率 X%→Y%。
```

> [!note] 改写的核心动作
> 数据岗把"模型"当**工具**（我用了离线 teacher）；算法岗把"数据"当**手段**（我用数据把指标做上去）。**同一件事，主语不同。**

## 三、两份项目卡（差异只在"决策"和"数字"）

### 数据算法岗版

- **背景**：回传 PB 级，人工挖掘+标注跟不上，迭代卡在 6 周。
- **决策**：① 规则召回 → 规则 + 表征检索 + 不确定性排序；② 人工全标 → 离线 teacher + 三级置信度 + 抽检；③ 加 4D 轨迹校验。
- **数字**：挖掘有效率 12%→38%；自动化率 55%→88%、返工率 35%→9%；周期 6 周→2 周。
- **坑**：只盯自动化率 → 返工率 40%，净成本反升；按净成本调阈值。
- **反思**：先建评测集，否则提升无法归因。

### 算法岗版

- **背景**：某类场景（施工区）连续三个版本是短板，公开数据补不上。
- **决策**：① 用检索定位"同类不同景"的样本，避免只补同款；② 用 4D 校验过滤脏标签，防"越训越差"；③ 做分切片回归，确认只在目标切片涨。
- **数字**：目标切片 +2.1 点；整体 NDS 持平；闭环通过率 +X%；延迟不变。
- **坑**：一开始只补"同款"数据，涨了 0.3 点就饱和；换成检索扩类后才涨 2 点。
- **反思**：**数据策略比数据量重要**——同样的标注预算，选样方式决定增益。

> [!tip] 算法岗版的"命门"
> 必须回答"**你怎么证明是数据带来的，不是训练随机性**"——同 baseline、同评测集、配对 bootstrap、多 seed。见 [[数据闭环的训练与评测]]。

## 四、三版陈述（各一套）

### 数据算法岗

- **30 秒**：做数据闭环，负责挖掘+标注；挖掘有效率 12→38%，自动化率 55→88%、返工率 9%，周期 6 周→2 周。
- **1 分钟**：背景（数据多、标不动、迭代慢）→ 三个决策（检索/分级/4D 校验）→ 数字 → 一个坑（返工率）。
- **3 分钟**：加"为什么用检索不用规则""置信度阈值怎么按净成本定""4D 校验抓了什么错"。

### 算法岗

- **30 秒**：做感知的数据侧，用数据闭环补长尾；施工区切片 +2.1 点、整体不掉、延迟不变。
- **1 分钟**：背景（某切片持续短板）→ 三个决策（检索扩类/4D 过滤脏标签/分切片回归）→ 数字 → 一个坑（只补同款会饱和）。
- **3 分钟**：加"怎么归因""为什么不用合成数据""如果让你改模型你会改哪"。

## 七、五种常见误投

| 误投 | 后果 | 改法 |
|------|------|------|
| 数据话术面算法岗 | "你模型能力呢" | 换成"切片 +2.1 点、整体不掉" |
| 算法话术面数据岗 | "你就是调模型的" | 换成"效率/成本/周期" |
| 简历一份通投 | 两边都不匹配 | 两版：数据版前置"效率"，算法版前置"指标" |
| 只讲流程不讲决策 | 像"执行者" | 每个项目准备 3 个"为什么这么选" |
| 没有失败故事 | 像"包装的" | 准备一个"我错在哪" |
