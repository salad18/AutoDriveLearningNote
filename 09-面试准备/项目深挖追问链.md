# 项目深挖追问链（数据闭环版）

> **用法**：面试官不会只问一层，他会沿五个方向往下钻——**为什么 / 怎么证明 / 成本多少 / 边界在哪 / 如果重来**。下面 6 条链，每条 6-7 层，照着练到"被追到第 5 层不慌"。

---

## 〇、先记住：追问的五个方向

```
① 为什么这么做？（方案选择）
② 怎么证明有效？（归因/指标）
③ 成本多少？（数据/算力/人力）
④ 边界在哪？（规模×10、数据变脏、传感器缺失）
⑤ 如果重来？（反思）
```

> [!tip] 答不上来的三步救场
> ① 复述问题确认理解（争取 10 秒）；② 说"我从 X 角度理解，大致是……"（给框架）；③ 诚实收尾："这块没深入，但我做过相关的 Y。"**沉默比答错更糟。**

## 链 1：挖掘与检索（最容易被追到第 6 层）

**Q1｜你们怎么找 corner case？**
三层漏斗：规则召回（接管/急刹/场景标签）→ 模型打分（不确定性/相似度）→ 多样性约束（去重/聚类/配额）。

**Q2｜规则不就行了，为什么要模型打分？**
规则召回高但精度低——接管里一堆"前车乱来"不是我们的问题；模型打分负责**排序**，把"模型真不会的"排前面。但打分前要先**校准**，否则低置信度筛出来的是噪声。

**Q3｜怎么保证捞出来的是"同一类"？**
先定义"相似"：视觉 embedding（外观）、BEV 特征（布局）、轨迹特征（行为）。危险场景常常**画面不像但行为像**，所以我会把轨迹特征也拼进去。捞完再人工核 100 个算认可率。

**Q4｜1 亿个 clip 怎么检索？**
场景向量按 2-5 秒切片，L2 归一化；建 IVF-PQ 索引（512 维 → 64 字节，205GB → 6.4GB），粗筛 top-1000，再用原始向量精排。

**Q5｜怎么证明这套检索有用？**
三层：Recall@K（人工标 200 个 query 的标准相似集）、人工认可率（捞回 100 个几个真有用）、下游指标（用检索出的数据训练后，该类场景是否涨）。

**Q6｜数据量翻 10 倍，方案还成立吗？**
成立但要改：分片建索引 + 离线批量检索 + 定期重建；成本线性上涨，所以更要控**每 MB 数据的模型增益**。

**Q7（陷阱）｜你说挖掘有效率提升了，怎么排除是标注质量也变好了？**
控制变量：同一版标注流水线、同一套评测集、同一训练配置；如果标注也改了，就做**两两消融**（只换数据 / 只换标注），把增益拆开。

## 链 2：自动标注（最容易露馅，也最容易加分）

**Q1｜你们自动标注怎么做？**
离线 teacher 三步：多帧检测 → 跟踪成 track → 序列精修；再做几何/多传感器一致性校验、轨迹级 4D 校验、置信度分级（A 直过 / B 人工快审 / C 全标）。

**Q2｜离线为什么比在线准？**
四个"时间红利"：能看未来帧、能累积点云（密度 ×5-10）、能用大模型、后处理预算从毫秒变分钟。本质是**用时间换精度**，再蒸馏回在线。

**Q3｜标签质量怎么保证？**
物理一致性优先于模型置信度：框内点数、重投影误差、轨迹加速度/朝向/ID 保持率；再加抽样金标准算 AP 差；盯**返工率**而不是只看自动化率。

**Q4｜4D 一致性具体校验什么？**
三条：运动学（加速度上限、朝向与速度方向一致）、外观（同 track 特征相似，防 ID 交换）、遮挡逻辑（不会无故消失又出现）。

**Q5｜OCC 真值怎么生成？坑在哪？**
LiDAR 多帧动静分离 → 聚合稠密化 → 体素化投票。坑：收费站抬杆残影（静态可动）、被挪动的锥桶/垃圾桶残影、小目标盲区闪现、上游分割/检测误差级联、算力存储爆炸。

**Q6｜自动化率 90%，返工率多少？**
（诚实给数）返工率高说明置信度阈值太松或缺少轨迹校验；我会按"净成本"调阈值，而不是按自动化率调。

**Q7（陷阱）｜上游检测漏了一个目标，OCC 里会出现什么？**
点云没被剥离 → 该目标被当成静态背景叠进地图 → 空间里出现"鬼影/杂点"；还会污染后续帧。解法是上游质量门禁 + 动静分离 + 人工抽检高动态区域。

## 链 3：训练与评测（决定你是"调参的"还是"做系统的"）

**Q1｜数据怎么配比？**
不是拍 70/30：按场景分层设桶 → 单桶 ±50% 消融 → learning curve 找饱和点 → 混比细扫 → hard set/闭环复验。

**Q2｜新数据加进去，老场景掉了怎么办？**
灾难性遗忘：先旧域回归确认退化，再混合训练（旧 70/新 30 起步）、回放 buffer、EWC 或冻结 backbone/LoRA。

**Q3｜涨了 0.5 点，怎么证明是数据的功劳？**
同一 baseline、同一评测集、同 seed；配对 bootstrap 看置信区间是否跨 0；分切片看是否只在某类涨；再看闭环是否同向。

**Q4｜开环涨了闭环不涨，为什么？**
开环喂人类轨迹，模型永远在"正确状态"；闭环一旦偏 20cm 就分布外，误差累积。解法：非反应式闭环（NAVSIM/PDMS）先看累积误差，再看反应式（Bench2Drive/CARLA）看交互。

**Q5｜评测集会不会过拟合？**
会。留出集"少用、后用、不调参"；发现 val 涨、留出集不涨就是信号；定期换新场景补充评测集。

**Q6｜你们迭代周期多久？瓶颈在哪？**
（给数）比如周级；瓶颈通常在标注返工和评测排队，不在训练。**闭环速度 = 最慢那一段**。

## 链 4：平台与工程（面平台岗才走这条）

**Q1｜数据量多大？怎么存？**
（给量级）PB 级；对象存储放原始 clip、列存/parquet 放结构化元数据、ES 做检索、向量库存 embedding；冷热分层。

**Q2｜回传链路怎么设计？**
车端触发 + 筛选 → 分级（P0 实时/P1 WiFi/P2 抽检）→ 差分/关键帧 → 云端去重入库；脱敏在车端或接入层做。

**Q3｜Spark 任务慢，怎么排查？**
先看 shuffle（数据倾斜/分区数）、再看序列化与文件数（小文件）、再看 join 策略（broadcast vs shuffle）；用 Spark UI 定位 stage 长尾。

**Q4｜怎么保证数据不丢不重？**
幂等写入（主键去重）+ 事务/两阶段提交 + 校验（条数/checksum）+ 血缘记录；重跑要能覆盖。

**Q5｜训练集群怎么调度？**
队列 + 优先级 + 抢占；小任务打包、大任务独占；GPU 利用率监控，避免"占着卡不跑"。

**Q6｜成本怎么控？**
存储分层 + 生命周期删除 + 冷数据压缩；训练侧早停/小模型预筛/冻结骨干；标注侧分级 + 返工率考核。

## 链 5：业务与动机（跳槽必问，答不好前面全白费）

**Q1｜为什么离开 ADS？**
**不要说前东家坏话**。说"想在 X 方向（纯视觉端到端 / 数据平台从 0 到 1）承担更大责任"，把动机落在**成长**而不是**逃离**。

**Q2｜为什么选我们？**
说三件具体的事：技术路线（如纯视觉/世界模型）、数据闭环的阶段（在建/成熟）、你能补的缺口（如检索/自动标注）。**别只夸公司大**。

**Q3｜你对我们数据闭环的判断？**
给一个**具体痛点**：纯视觉公司缺 LiDAR 几何真值 → 靠重建/多视角补；低成本公司算力紧 → 数据效率/量化；Robotaxi 长尾 → 仿真 + 安全冗余。

**Q4｜你期望做什么方向？**
给"主 + 辅"：主做挖掘/自动标注，辅做评测/平台；**别说"都可以"**，显得没想法。

**Q5｜竞业有没有问题？**
如实说流程（已确认/在确认），不展开细节；**不要承诺"肯定没问题"**。

## 链 6：失败与复盘（筛"真做过"的最后一关）

**Q1｜讲一个失败的项目。**
选**技术性失败**（不是人际），说清：目标 → 你当时的判断 → 实际结果 → 根因 → 后来怎么改。**必须有"我错在哪"**。

**Q2｜和上下游冲突怎么处理？**
举一个"标注规范和感知需求不一致"的例子：拿数据说话（抽样对比）、定共同指标、小范围试点。

**Q3｜你做过最"脏"的活是什么？**
别说"没有"。说数据清洗/对齐/补标——**脏活里能讲出工程洞察**（如"发现 30% 的 bad case 其实是标定漂移"）。

**Q4｜如果重来，你会改哪件事？**
给一个**具体的顺序错误**：比如"先做检索再做规则""先建评测集再调模型"。

|----|--------------------------|
| 挖掘 | 数据量级、挖掘有效率、Recall@K、索引方案 |
| 标注 | 自动化率、返工率、4D 校验三条、OCC 三个坑 |
| 训练 | 配比方法、回放比例、蒸馏对象 |
| 评测 | 门禁条数、开环/闭环差异、置信区间 |
| 平台 | 存储选型、回传分级、Spark 排查顺序 |
