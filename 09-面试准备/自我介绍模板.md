# 自我介绍模板（30s / 1min / 3min 三版）

> 一句话导读：自我介绍是**面试的第一道题，也是唯一你能 100% 提前准备好的题**。本篇给三个版本（对应不同场景）+ 一个万能公式 + 常见坑。核心思路：**不背简历，讲"我是谁 + 我做了什么 + 为什么适合你"**。

---

## 🧭 本篇导读

| 项目 | 内容 |
|------|------|
| **这篇学什么** | 三版自我介绍模板（可直接改写）、万能公式、每版适用场景、常见坑 |
| **配套** | [[简历项目-端到端自动驾驶小车]]（你的核心故事）、[[面试准备策略]]（整体策略）|
| **学完之后你能** | ① 30 秒内说清"我是谁"；② 1 分钟内带出项目亮点；③ 3 分钟版本能讲完整故事并埋钩子 |
| **预计阅读时间** | 20 分钟（含改写练习）|

> [!tip] 万能公式：**定位 → 能力 → 证据 → 钩子**
> 1. **定位**（10%）：一句话说清你是谁/什么方向
> 2. **能力**（30%）：2-3 个核心能力（要和 JD 对齐）
> 3. **证据**（50%）：每个能力配一个量化证据（项目/论文/课程）
> 4. **钩子**（10%）：结尾抛一句"我对 XX 特别感兴趣，希望有机会深聊"——引导面试官问你准备过的方向

## 一、30 秒版（电梯陈述，群面/开场）

> 适用：开场白、路上偶遇、HR 初筛电话。**只说定位 + 一个最强亮点。**

```
面试官您好，我是 XXX，XX 大学 XX 专业。我的方向是自动驾驶感知算法，
重点研究 BEV 感知和端到端驾驶。最近在做一个端到端自动驾驶小车的
个人项目，从数据采集到闭环测试完整跑通，最让我骄傲的是解决了
"离线指标好但闭环翻车"的分布漂移问题。我对贵司的 XX 方向特别
感兴趣，希望今天能深入聊一聊。
```

**要点**：≤30 秒（约 100 字）、只留一个亮点、结尾抛钩子。

---

## 二、1 分钟版（一面技术面开场）

> 适用：技术一面。**定位 + 2 个能力 + 各自证据。**

```
面试官您好，我是 XXX，XX 大学 XX 专业，主攻自动驾驶感知与端到端方向。

第一，我有扎实的模型基础。系统学完了 BEV 感知（LSS/BEVFormer/PETR）、
Transformer、端到端（UniAD/VAD）的完整体系，并且把每个概念都整理成
了带推导和自测的教学笔记。

第二，我有完整的动手实践。独立做了端到端自动驾驶小车项目：树莓派
采集数据 → 在无 GPU 的环境用 CPU 训练 + DirectML 推理 → 装回小车
闭环测试，通过失败模式驱动的迭代把赛道完成率从 X% 提升到 X%。
这个过程让我真正理解了分布漂移和数据闭环——也就是量产团队每天
在解决的问题。

我对贵司 XX 方向很感兴趣，特别想了解您这边在 XX 上的技术路线。
```

**要点**：≤60 秒、能力要对齐 JD 关键词、证据带数字、结尾问题化。

## 三、3 分钟版（主管面/终面）

> 适用：主管面、交叉面。**完整故事：为什么做这个方向 + 项目深讲 + 规划。**

```
面试官您好，我是 XXX，XX 大学 XX 专业。

【为什么选这个方向】我本科/硕士期间系统学习了机器学习，后来被自动
驾驶"一个系统要同时解决感知、预测、规划"的复杂度吸引，决定深耕
自动驾驶算法。我给自己定了一条学习主线：从模型基础（CNN/Transformer）
到 BEV 感知，再到端到端和 VLA，每一站都要求"能讲清 + 能推导 + 能自测"。

【做了什么】知识层面，我建立了 40+ 篇教学笔记的完整知识库，覆盖
BEV 感知、多传感器融合、端到端、VLA 前沿，并精读了 7 篇 2025-2026
年最前沿的论文（包括世界模型、ChainFlow-VLA 等），每篇都整理成
带架构图和面试追问的解读。实践层面，我独立完成了端到端自动驾驶
小车项目，跑通"采集→训练→闭环"全流程，解决了分布漂移问题，
量化记录每一次迭代。

【为什么适合贵司】我了解到贵司在 XX 方向上（如无图方案/端到端/
VLA 部署）投入很大，这和我知识库里的研究主线高度一致。我特别想
把对 BEV 和端到端的理解，放到真实量产场景里去验证。未来 3-5 年
我希望深耕感知/端到端方向，成长为能独立负责一个模块的算法工程师。

【钩子】我准备了一些对贵司技术方案的理解和问题，希望在后面环节
和您交流。
```

**要点**：故事有主线（为什么→做了什么→为什么是你）、提到公司具体方向（面试前查！）、结尾给"我准备过"的信号。

## 四、常见坑（对照检查）

| 坑 | 为什么不行 | 正确做法 |
|----|-----------|---------|
| **背简历** | 面试官手里就有简历，浪费时间 | 讲简历上没有的：动机、取舍、反思 |
| **堆技能名词** | "熟悉 Pytorch/熟悉 Transformer/熟悉..." = 没有重点 | 每个能力配一个证据 |
| **没对齐 JD** | 自我介绍和岗位无关 | 面试前把 JD 关键词抄下来，塞进"能力"部分 |
| **不埋钩子** | 面试官只能随机提问，可能问到你没准备的 | 结尾抛"我对 XX 很感兴趣"，引导提问方向 |
| **超时** | 面试官打断，节奏被打乱 | 每个版本卡时间练，宁可短不可长 |
| **无数字** | "做了个项目"没有说服力 | 完成率、延迟、笔记数、论文数，全用数字 |

## ✅ 自测一下

> [!question] Q：30 秒版里"最强亮点"应该选什么？

> [!success]- 参考答案
> 选**和 JD 最相关**的亮点，不是你自己觉得最牛的。投感知岗就讲小车项目的闭环解决；投 VLA 岗就讲 7 篇论文精读 + VLA 知识体系。一句话：**JD 要什么，你第一句就给什么。**

> [!question] Q：1 分钟版的"能力"部分怎么选 2 个？

> [!success]- 参考答案
> 公式：**1 个硬核技术能力**（模型/算法，对齐 JD）+ **1 个差异化能力**（动手实践/学习体系/工程落地）。两个都要有证据。不要 3 个——1 分钟讲 3 个必然每个都很浅。

## 🛠 动手练习

1. **改写**：把三版模板里的 XXX/XX 换成你的真实信息，项目证据从 [[简历项目-端到端自动驾驶小车]] 版本 A/B 里取。
2. **计时**：30 秒版念 5 遍（目标 100 字内）；1 分钟版念 3 遍；3 分钟版念 1 遍。
3. **录音回放**：听有没有"然后/那个/嗯"口头禅，删掉。
4. **对镜练**：语速放慢 20%（紧张会不自觉加速）。
5. **对齐 JD**：拿一个真实 JD（如华为感知岗），把它的关键词圈出来，改一版"定制自我介绍"。
