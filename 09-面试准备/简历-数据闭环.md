## 指标口径表（填 X/Y 前先看）

| 指标 | 怎么算 | 拿不到怎么办 |
|------|--------|--------------|
| **挖掘有效率** | 人工认可"有价值"的样本 / 回传样本数 | 用相对值："提升 3 倍" |
| **自动化率** | 免人工标签数 / 总标签数 | 用"从过半到接近全自动" |
| **返工率** | 被人工打回修改的标签 / 自动标签数 | 用"降到个位数" |
| **迭代周期** | bad case 发现 → 新模型上线 | 用"月级 → 周级" |
| **切片提升** | 目标场景指标 before / after | 用"+X 点，整体持平" |
| **成本** | （标注 + 存储 + 算力）/ 帧 | 用"单帧成本降 X%" |

> [!warning] 三条红线
> ① 不写具体客户/车型/项目代号；② 不写未公开的绝对指标；③ 只写你真能解释口径的数字——**面试官一定会追问"怎么算的"**。

## 排版与投递（一页版）

- **长度**：社招 1 页，校招/实习 1 页；超过 1 页先删"自我评价"和与岗位无关的技能。
- **顺序**：数据岗 = 概述 → 能力 → 工作 → 项目 → 教育；算法岗 = 概述 → 能力（模型在前）→ 工作 → 项目 → 教育。
- **字号**：正文 10.5–11pt，行距 1.15–1.25；模块标题加粗，不要花哨配色。
- **导出**：Word 另存 PDF，命名 `姓名-数据算法-数据闭环-X年.pdf`。
- **投递**：网申填"可复制版"，邮件正文贴 3 行概述 + 附件 PDF。
