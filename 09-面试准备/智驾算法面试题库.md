## 二、大模型 / VLA 方向新增题（2025 热点，Q23-Q32）

> 每题三件套：问题 + 答题框架（先结论→展开→举例）+ 关联笔记。答案要点直接引用本库教学版笔记，深读见关联笔记。

### Q23: VLM 和 VLA 的区别？⭐⭐⭐ 高频

**答题框架**：
- 结论：VLA = VLM + 动作头，输出从"文字"扩展到"动作"。
- 展开：VLM 会看会想不会动手（输出文字描述/决策）；VLA 会看会想会动手（输出动作，可附语言解释）。结构上 VLA 多了"动作头"（离散化/回归/Flow Matching 三种动作表示）。
- 举例：DriveVLM 输出"前方有行人应减速"（VLM），DriveVLA/π0 直接输出"减速动作 + 解释"（VLA）。

> 📚 深读：[[VLA入门与智驾应用]] 第一节

### Q24: VLA 的动作表示有哪些方案？π0 为什么用 Flow Matching？⭐⭐⭐

**答题框架**：
- 结论：三种方案——动作离散化（token 化）、连续回归头（MLP）、Flow Matching/扩散（生成式）。
- 展开：离散化复用 LLM token 生成但有量化误差；回归简单但表达力弱（只能给"平均答案"）；Flow Matching 把动作当生成问题，能表达多模态动作（同一指令多种合理轨迹）。
- 举例：π0 用 Flow Matching；RT-2 用离散化。

> 📚 深读：[[VLA入门与智驾应用]] 3.2

### Q25: VLA 智驾和 UniAD 的区别？⭐⭐⭐ 高频

**答题框架**：
- 结论：UniAD 是无语言的"感知-规划"网络，VLA 加了 LLM 推理层。
- 展开：能力上 VLA 多"常识推理 + 语言解释"（可处理"警车让行"常识）；代价是推理慢、会幻觉、数据要求高（图+语言+动作三对齐）。
- 举例：当前量产是分层——VLA 做高层决策，传统模型做高频控制（华为 PDP+CAS 同哲学）。

> 📚 深读：[[VLA入门与智驾应用]] 第五、七节

### Q26: VLA 智驾怎么解决实时性？⭐⭐⭐

**答题框架**：
- 结论：分层架构——VLA 低频决策 + 传统模型高频控制。
- 展开：VLA（LLM）推理秒级，做"场景理解/行为选择"（低频）；传统模型毫秒级，做"轨迹跟踪/执行"（高频）。类比"大脑 vs 小脑"。
- 举例：华为 PDP（端到端决策）+ CAS（规则兜底）+ 底层控制——大脑升级成 VLA 后同构。

> 📚 深读：[[VLA入门与智驾应用]] 挑战 1、[[华为ADS端到端架构]]

### Q27: VLA 的幻觉问题怎么防？⭐⭐⭐

**答题框架**：
- 结论：感知层验证 + RLHF 安全对齐 + 规则兜底。
- 展开：VLA 可能"看到"不存在的物体/规则（假阳性 → 错误动作）→ ① 传统感知先验证（VLA 只做高层推理）；② RLHF 让模型学会"不确定就说不知道"；③ 幻觉输出不进控制链路（规则兜底）。
- 举例：[[大模型与自动驾驶]] 的"感知+语言双层验证"。

> 📚 深读：[[大模型与自动驾驶]] 挑战 2、[[VLA入门与智驾应用]] 挑战 2

### Q28: 智驾和具身智能（机器人）的共通点？你会怎么迁移？⭐⭐ 转行必问

**答题框架**：
- 结论：智驾 = 轮式具身智能，共用 VLA 底座。
- 展开：同样的"视觉编码器 + LLM + 动作头"结构；动作空间不同（转向/油门 vs 关节）；训练范式相同（三阶段）；世界模型/端到端方法共享。
- 举例：迁移 = 共享 VLA 预训练 + 换动作头微调——"转行就是换动作空间"。

> 📚 深读：[[VLA入门与智驾应用]] 第二节、[[具身智能热点追踪]]（待扩充）

### Q29: 世界模型在智驾/机器人的作用？⭐⭐

**答题框架**：
- 结论：让系统"预测未来"——安全验证（事前推演）、数据增强（生成 corner case）、辅助训练信号、闭环仿真。
- 展开：GAIA-1（像素级）vs OccWorld（占据级）的表示选择；DriveVLA-W0 用世界模型合成 VLA 训练数据（新趋势）。
- 举例：规划前用世界模型"脑内模拟"变道安全性。

> 📚 深读：[[世界模型]] 第三、四节、[[VLA入门与智驾应用]] 代表模型

### Q30: 大模型后训练（Post-training）的主流方法？⭐⭐⭐

**答题框架**：
- 结论：RLHF / DPO / GRPO 三大类，核心是"偏好对齐 + 锚定 SFT"。
- 展开：RLHF 三步（奖励模型 + PPO + KL 约束）；DPO 消掉奖励模型（直接偏好对优化）；GRPO 消掉 Critic（组内相对优势）。2025 热点：GRPO 的 on/off-policy 分析。
- 举例：AutoDrive-P3 用 GRPO 奖励"格式+感知+预测+规划"四部分（奖励中间推理防假性成功）。

> 📚 深读：[[三阶段训练范式]] 第四节、[[大模型训练技巧进阶]]（待扩充）

### Q31: 智驾数据的"数据闭环"和 VLA 的"数据饥渴"怎么解决？⭐⭐

**答题框架**：
- 结论：数据闭环（采集-挖掘-标注-训练-OTA）+ 世界模型合成数据。
- 展开：影子模式采集 corner case；VLA 还需"语言/推理"标注（更贵）→ 自动化语言标注 + 世界模型合成（DriveVLA-W0）。
- 举例：特斯拉 Fleet Learning vs 华为 5 天迭代；DriveVLA-W0 用世界模型放大数据规模。

> 📚 深读：[[数据闭环总览]]、[[VLA入门与智驾应用]] 第六节

### Q32: 端到端模型出事故怎么 debug？⭐⭐⭐

**答题框架**：
- 结论：特征可视化 + 模块 probe + 反事实分析 + 影子模式 + 分体式兜底。
- 展开：attention map 看"看着哪里"；probe classifier 检查中间表示质量；改输入看输出变化定位依赖；影子模式积累 bad case；规则兜底保证"至少知道违反了什么"。
- 举例：华为 GOD+PDP 分体式 = "端到端决策 + 规则兜底"。

> 📚 深读：[[常见面试题-感知算法]] Q18、[[华为ADS端到端架构]]

## 五、通用答题方法论（面试技巧）

### 技术题万能框架：**先结论 → 展开 → 举例**

```
第 1 句（结论）:   一句话说清"是什么/怎么选"（10 秒内给出判断）
第 2-3 句（展开）: 结构/原理/对比（讲清楚"为什么"）
第 4 句（举例）:   项目/论文/数值例子（证明你真的做过）
```

### 追问应对：**三层防线**

```
第一层: 定义与直觉（"是什么"）——基础分
第二层: 原理与对比（"为什么/区别"）——加分
第三层: 数据与权衡（"数值/代价/怎么选"）——满分（展示工程感）
```

### 不知道答案时的应对

```
1. 复述问题确认理解（争取思考时间）
2. 说"从 XX 角度理解"（展示分析框架，即使不完整）
3. 诚实说"这部分没深入，但我了解相关的 XX"（比硬编强）
```

> [!note] 练习方式（结合自测题）
> 找一个小伙伴或对着录音，随机抽题，用"先结论→展开→举例"练 30 秒即兴回答。**面试是"脱口而出"的比赛，不是"想出来"的比赛**——多练即兴，考场不慌。

## 六、检验自己（模拟面试自测）

> [!question] Q1：用"先结论→展开→举例"框架，60 秒内回答："VLA 智驾能落地量产吗？"
> 提示：分层架构 + 数据瓶颈 + 华为/理想案例。

> [!success]- 参考框架
> 结论：能，但以"分层架构"形式落地（VLA 决策 + 传统控制），不是纯 VLA 端到端。展开：① 实时性——LLM 秒级推理做不了 100ms 控制，VLA 做低频高层决策、传统模型做高频执行；② 数据——VLA 需要"图+语言+动作"三对齐数据，靠互联网预训练 + 世界模型合成解决；③ 安全——幻觉必须感知层验证 + 规则兜底。举例：华为 PDP+CAS 分层（大脑升级成 VLA 同构）、DriveVLA-W0 用世界模型造数据。

> [!question] Q2：你做过智驾感知，面试官问"能转机器人吗"，你怎么答？
> 提示：VLA 底座 + 动作空间。

> [!success]- 参考框架
> 结论：能，智驾是轮式具身智能，共用 VLA 底座。展开：同样的视觉编码器 + LLM + 动作头结构，只是动作空间不同（转向/油门 vs 关节）；训练范式相同（三阶段）；世界模型/端到端方法共享。举例：π0 一个 VLA 控制多种机器人，说明"换本体 = 换动作头微调"——我具备的是共享底座的迁移能力。

> [!question] Q3：随机抽第二节任意一道题（Q23-Q32），对着录音 60 秒回答，然后回放检查。
> 提示：先结论→展开→举例；答完对照参考答案。

> [!success]- 自检清单
> ① 10 秒内给出结论了吗？② 展开有结构（原理/对比）吗？③ 举例是"真实细节"还是"泛泛而谈"？④ 全程没有"嗯…啊…"的长时间停顿？——四项都过，这题算过关。

## 七、常见误区速查

> [!warning] 面试准备最常踩的坑
> 1. **只背不练**——看了答案 ≠ 能说出口，必须对着录音即兴练（面试是口试不是笔试）。
> 2. **只刷新题不固旧**——经典题（BEVFormer/LSS/NDS）才是高频基石，VLA 新题是加分项，别本末倒置。
> 3. **答题没有框架**——"知道但说不清"= 没准备过；用"先结论→展开→举例"。
> 4. **不记面经**——面试完不复盘 = 白面；每题记进本节"高频记录"。
> 5. **忽略数值**——"NDS 56.9 vs 48.8""碰撞率降 15 倍"这类数值是说服力的来源（[[模型基础知识补充]] 有指标表）。
