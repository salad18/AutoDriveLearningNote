## 二、🔥 高优先级缺口（投递前必须补，面试直接问）

### 1. Python 手撕能力 ✅（2026-08 已完成）

- **为什么**：感知算法面试的"算法题"是**模型算法推导 + 白板实现**（非 LeetCode）；一面高频出 Attention/NMS/IoU/Loss 手写。
- **补什么**：Self-Attention / NMS / IoU / Focal Loss / BN-LN-GN / RoPE 的 numpy 实现 + 复杂度 + 数值稳定性。
- **动作**：✅ 已建 [[手写算法-Python版]]（手撕 6 件套，numpy 逐行实现 + 面试追问 + 6 天练习计划）。
- **提示**：若目标华为/地平线/Momenta 的 C++ 岗，后续可在 Python 版基础上对照 [[手写算法-Python版]] 转 C++（[Autonomous-Driving-Cpp](https://github.com/Yicen-y/Autonomous-Driving-Cpp)），暂不阻塞投递。

### 2. 源码级工程理解（mmdet3d / OpenPCDet）

- **为什么**：百度/小鹏/美团 JD 要求"mmdet3d 熟练 + 源码级理解"。
- **补什么**：BEVFormer / CenterPoint 训练→推理全链路走读（数据加载→backbone→neck→head→loss→后处理→评估）。
- **动作**：新建 `05-论文阅读/源码走读-BEVFormer(mmdet3d).md`；读 [[BEVFormer详解]] 时对照代码。

### 3. 一个可深挖的真实项目 ✅（2026-08 已完成"怎么讲"，动手进行中）

- **为什么**：简历模板有 STAR 示例，但没有**真实可讲**的项目（[[面试准备策略]] 二节）。
- **补什么**：把 [[小车项目总览]] 的端到端小车 + [[本地训练方案]] 串成一个完整项目：采集→训练→闭环测试→量化指标（mAP/延迟/成功率）。
- **动作**：✅ 已建 [[简历项目-端到端自动驾驶小车]]（可复制简历描述 A/B 版 + STAR 拆分 + 30 秒电梯陈述 + 6 层深挖问答 + 方案对比表）。
- **待办**：⚠️ 简历里的 X/Y/Z 数字需按实际动手进度填写（[[简历项目-端到端自动驾驶小车]] 有提示）；配套 [[自我介绍模板]]（30s/1min/3min）已建。

### 4. 部署实操（TensorRT 落地）

- **为什么**：地平线 BPU / 华为感知岗必问 INT8 量化与端侧延迟。
- **补什么**：[[模型部署与延迟优化]] 有理论，缺一次真跑：PyTorch→ONNX→TensorRT→INT8，记录延迟/精度。
- **动作**：在 [[本地训练方案]] 或小车项目里加"部署小节"，产出量化前后对比表。
