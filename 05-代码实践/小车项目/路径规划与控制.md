# 🧭 路径规划与控制

> 知道自己在哪 + 知道要去哪 → 路径规划。把路径变成轮子指令 → 控制。

---

## 一、规划 vs 控制的层次

```
┌─────────────────────────────────────────────┐
│  全局规划 (Global Planner)    ← 地图级       │
│  A* / Dijkstra / RRT*        ← 秒级更新     │
├─────────────────────────────────────────────┤
│  局部规划 (Local Planner)     ← 10-100ms 级  │
│  DWA / TEB / Pure Pursuit     ← 避障+轨迹    │
├─────────────────────────────────────────────┤
│  控制器 (Controller)          ← 1-10ms 级    │
│  PID / Stanley / MPC          ← 执行器指令   │
└─────────────────────────────────────────────┘
```

> 循迹小车 (L1)：不需要规划，直接反馈控制。
> 导航小车 (L3+)：全局 A* 规划 → 局部 DWA 避障 → PID 执行。

---

## 二、全局路径规划

### A* 算法

最经典的图搜索算法。在栅格地图上找从起点到终点的最短路径。

```
代价函数: f(n) = g(n) + h(n)
  g(n): 从起点到 n 的实际代价（已走路程）
  h(n): 从 n 到终点的启发式估计（直线距离）

A* 保证找到最短路径（当 h(n) 是 admissible 时）
```

```python
import heapq

def astar(grid, start, goal):
    """grid: 2D list, 0=free, 1=obstacle"""
    rows, cols = len(grid), len(grid[0])
    
    def heuristic(a, b):
        return abs(a[0]-b[0]) + abs(a[1]-b[1])  # 曼哈顿距离
    
    open_set = [(0, start)]
    came_from = {}
    g_score = {start: 0}
    
    while open_set:
        _, current = heapq.heappop(open_set)
        
        if current == goal:
            # 回溯路径
            path = []
            while current in came_from:
                path.append(current)
                current = came_from[current]
            path.append(start)
            return path[::-1]
        
        for dx, dy in [(0,1),(1,0),(0,-1),(-1,0)]:  # 四邻域
            neighbor = (current[0]+dx, current[1]+dy)
            if not (0 <= neighbor[0] < rows and 0 <= neighbor[1] < cols):
                continue
            if grid[neighbor[0]][neighbor[1]] == 1:
                continue
            
            tentative_g = g_score[current] + 1
            if tentative_g < g_score.get(neighbor, float('inf')):
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                f = tentative_g + heuristic(neighbor, goal)
                heapq.heappush(open_set, (f, neighbor))
    
    return None  # 无路径
```

### RRT (Rapidly-exploring Random Tree)

**适用场景**：连续空间、非栅格地图、高自由度。

```python
# 简化版 RRT 思路
def rrt(start, goal, obstacles, max_iter=1000, step=0.1):
    tree = [start]  # 树节点
    parent = {start: None}
    
    for _ in range(max_iter):
        # 1. 随机采样
        if random.random() < 0.1:
            sample = goal  # 10% 概率直接朝向目标
        else:
            sample = (random.uniform(-5,5), random.uniform(-5,5))
        
        # 2. 找最近节点
        nearest = min(tree, key=lambda n: dist(n, sample))
        
        # 3. 朝采样点延伸一步
        direction = ((sample[0]-nearest[0]), (sample[1]-nearest[1]))
        length = math.hypot(*direction)
        new = (nearest[0] + direction[0]/length * step,
               nearest[1] + direction[1]/length * step)
        
        # 4. 碰撞检测
        if is_collision(nearest, new, obstacles):
            continue
        
        # 5. 加入树
        tree.append(new)
        parent[new] = nearest
        
        if dist(new, goal) < step:
            return reconstruct_path(parent, new)  # 到达目标！
    
    return None
```

### 小车用哪个？

| 场景 | 推荐算法 | 理由 |
|------|----------|------|
| 有栅格地图（SLAM 建图） | A* | 最优、确定性强 |
| 无地图、有障碍物 | RRT | 探索性好 |
| ROS2 现成方案 | `nav2` 的 Smac Planner | 基于 A* 的改进版 |
| 循迹场景 | 不需要 | PID 反馈够用 |

## 三、局部避障

### DWA (Dynamic Window Approach)

在速度空间 `(v, ω)` 中采样，评估每条轨迹，选最优：

```
评分 = α·朝向目标 + β·远离障碍 + γ·速度大

速度窗口 = 动力学可达速度 ∩ 安全不撞的速度
```

```python
# DWA 简化伪代码
def dwa(current_pose, goal, obstacles):
    best_score = -inf
    best_v, best_w = 0, 0
    
    for v in linspace(v_min, v_max, 20):
        for w in linspace(w_min, w_max, 20):
            # 模拟轨迹
            traj = simulate(current_pose, v, w, dt=0.1, steps=20)
            
            # 评分
            heading = score_heading(traj[-1], goal)   # 朝向目标
            clearance = score_clearance(traj, obstacles)  # 离障碍物远
            velocity = v / v_max                      # 速度快
            
            score = α * heading + β * clearance + γ * velocity
            
            if score > best_score and clearance > 0:
                best_score = score
                best_v, best_w = v, w
    
    return best_v, best_w
```

> ROS2 `nav2` 内置了 DWA 和 TEB (Timed Elastic Band)，直接用即可。

## 四、路径跟踪控制器

有了路径（waypoints 序列），怎么让车轮准确沿着路径走？

### Pure Pursuit（纯追踪）

最经典的几何路径跟踪。核心思想：车前一定距离找一个目标点，转方向盘去追它。

```
          目标点 (lookahead)
         /
        /
       /  L (前视距离)
      /
     ☆ ← 圆弧
    /
   ● (后轴中心)
```

```python
def pure_pursuit(current_pose, path, lookahead=0.5, wheelbase=0.2):
    """返回转向角"""
    # 1. 找前视距离处的目标点
    target = None
    for i, pt in enumerate(path):
        if dist(current_pose[:2], pt) >= lookahead:
            target = pt
            break
    
    if target is None:
        return 0.0
    
    # 2. 转换到车辆坐标系
    dx = target[0] - current_pose[0]
    dy = target[1] - current_pose[1]
    
    # 旋转到车体坐标
    cos_t = math.cos(-current_pose[2])
    sin_t = math.sin(-current_pose[2])
    dx_local = dx * cos_t - dy * sin_t
    dy_local = dx * sin_t + dy * cos_t
    
    # 3. 纯追踪公式: δ = arctan(2·L·sin(α) / Ld)
    #    α 是前视点到车体纵轴的角度
    alpha = math.atan2(dy_local, dx_local)
    curvature = 2 * math.sin(alpha) / lookahead
    steering_angle = math.atan(curvature * wheelbase)
    
    return steering_angle
```

### Stanley 控制器

Stanley 是 Pure Pursuit 的改进版，多了一个横向误差项：

```python
def stanley_control(current_pose, path, velocity, k=0.5):
    """返回转向角"""
    # 1. 找最近路径点
    nearest_idx = min(range(len(path)), 
                      key=lambda i: dist(current_pose[:2], path[i]))
    
    # 2. 计算横向误差 (cross-track error)
    target = path[nearest_idx]
    dx = target[0] - current_pose[0]
    dy = target[1] - current_pose[1]
    
    # 横向误差 (带符号)
    cte = dx * math.sin(-current_pose[2]) + dy * math.cos(-current_pose[2])
    
    # 3. 航向误差
    target_heading = math.atan2(
        path[min(nearest_idx+1, len(path)-1)][1] - path[nearest_idx][1],
        path[min(nearest_idx+1, len(path)-1)][0] - path[nearest_idx][0]
    )
    heading_error = target_heading - current_pose[2]
    heading_error = math.atan2(math.sin(heading_error), math.cos(heading_error))
    
    # 4. Stanley 公式:
    #    δ = heading_error + arctan(k·cte / v)
    steering = heading_error + math.atan2(k * cte, max(velocity, 0.1))
    
    return max(-0.6, min(0.6, steering))  # 限幅
```

### MPC (Model Predictive Control)

MPC 是"工业级"控制器：在每个时刻求解一个优化问题，考虑未来 N 步的最优控制。

```python
"""
MPC 的核心优化问题（简化）:
    min Σ (x_k - x_ref)² · Q + Σ u_k² · R
     s.t. x_{k+1} = f(x_k, u_k)    # 动力学约束
           x_min ≤ x_k ≤ x_max     # 状态约束
           u_min ≤ u_k ≤ u_max     # 控制约束

对小车来说，MPC 通常 overkill。PID / Pure Pursuit 足够。
MPC 的价值在你知识库的 L4 量产车场景（考虑轮胎滑移、执行器延迟等）。
"""
```

| 控制器 | 复杂度 | 效果 | 适用 |
|--------|:--:|------|------|
| **PID** | 最低 | 简单线性好 | L1 循迹 |
| **Pure Pursuit** | 低 | 几何直观 | L2-L3 路径跟踪 |
| **Stanley** | 低 | 比 PP 多了横向误差 | L3 精确跟踪 |
| **MPC** | 高 | 最优但费算力 | L4 高速/高精度 |

## 五、状态机（行为决策）

在"规划"和"控制"之间，需要一个行为决策层：

```python
class StateMachine:
    """
    States:
        LANE_FOLLOW  — 正常车道保持
        OBSTACLE_AHEAD — 前方障碍，减速
        STOPPING     — 停车
        OVERTAKE     — 绕行（如果有空间）
        EMERGENCY    — 急停
    """
    def __init__(self):
        self.state = "LANE_FOLLOW"
    
    def update(self, perception, localization):
        front_dist = perception.get('front_distance', 999)
        left_dist = perception.get('left_distance', 999)
        
        if front_dist < 0.15:
            self.state = "EMERGENCY"
        elif front_dist < 0.5:
            if left_dist > 0.4:
                self.state = "OVERTAKE"
            else:
                self.state = "STOPPING"
        else:
            self.state = "LANE_FOLLOW"
        
        return self.state

# 规划器根据状态选择策略
if state == "LANE_FOLLOW":
    cmd = lane_follower(image)
elif state == "STOPPING":
    cmd = (steer=90, throttle=0)
elif state == "EMERGENCY":
    cmd = (steer=90, throttle=-255)  # 全速倒车/刹车
```
