## 一、摄像头（视觉感知）

### USB 摄像头选型

| 参数 | 推荐值 | 原因 |
|------|--------|------|
| 分辨率 | 640×480 或 1280×720 | 太高推理慢，太低检测不到 |
| 帧率 | 30fps 起步 | <15fps 控制延迟太大 |
| 视场角(FOV) | 100°~120° 广角 | 窄角看不到路口两侧 |
| 对焦 | 固定焦距 | 自动对焦在颠簸路面会反复对焦 |
| 接口 | USB 免驱 | 即插即用 |

### 相机标定（去畸变）

```
准备棋盘格 (9×6 内角点)，打印贴在硬板上。
从不同角度拍 20-30 张照片，运行标定脚本。
```

```python
import cv2
import numpy as np
import glob

CHECKERBOARD = (9, 6)
objpoints = []   # 3D 世界坐标
imgpoints = []   # 2D 图像坐标

objp = np.zeros((CHECKERBOARD[0]*CHECKERBOARD[1], 3), np.float32)
objp[:,:2] = np.mgrid[0:CHECKERBOARD[0], 0:CHECKERBOARD[1]].T.reshape(-1,2)

images = glob.glob('calib_images/*.jpg')
for fname in images:
    img = cv2.imread(fname)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    ret, corners = cv2.findChessboardCorners(gray, CHECKERBOARD, None)
    if ret:
        objpoints.append(objp)
        imgpoints.append(corners)

ret, mtx, dist, rvecs, tvecs = cv2.calibrateCamera(
    objpoints, imgpoints, gray.shape[::-1], None, None)

# 保存标定结果
np.savez('camera_calib.npz', mtx=mtx, dist=dist)

# 去畸变使用
frame = cv2.undistort(frame, mtx, dist)
```

## 二、超声波（HC-SR04）

### 原理

Trig 脚发 10μs 高电平 → 模块发 8 个 40kHz 脉冲 → Echo 脚返回高电平，高电平时长 = 声波往返时间。

$$\text{距离(cm)} = \frac{\text{Echo 高电平时长(μs)}}{58}$$

### Arduino 代码

```cpp
#define TRIG 12
#define ECHO 13

float readUltrasonic() {
    digitalWrite(TRIG, LOW);
    delayMicroseconds(2);
    digitalWrite(TRIG, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG, LOW);
    
    long duration = pulseIn(ECHO, HIGH, 30000);  // 30ms 超时 = ~5m
    if (duration == 0) return 999;  // 超时 = 无障碍
    
    return duration / 58.0;  // 厘米
}
```

### 注意事项

| 问题 | 原因 | 解决 |
|------|------|------|
| 读数偶尔跳变 | 反射面角度问题 | 中值滤波（取5次中位数） |
| 近距离不准 | 余震，盲区 ~2cm | 近距离改用 ToF |
| 多个互相干扰 | 交叉回波 | 分时触发，间隔 50ms |
| 软表面测不到 | 吸音材料 | 正常现象，超声波局限 |

```cpp
// 中值滤波
float readUltrasonicFiltered(int samples = 5) {
    float readings[5];
    for (int i = 0; i < samples; i++) {
        readings[i] = readUltrasonic();
        delay(10);
    }
    std::sort(readings, readings + samples);
    return readings[samples / 2];  // 中位数
}
```

## 三、IMU（MPU6050 / MPU9250）

### 获取的数据

| 数据 | 含义 | 用途 |
|------|------|------|
| **加速度计** (ax, ay, az) | 三轴加速度 | 倾角估计、碰撞检测 |
| **陀螺仪** (gx, gy, gz) | 三轴角速度 | 转向速率、姿态更新 |
| **磁力计** (9250) | 地磁方向 | 绝对航向（无 drift） |

### Arduino 读取（MPU6050）

```cpp
#include <Wire.h>
#include <MPU6050.h>

MPU6050 mpu;

void setup() {
    Wire.begin();
    mpu.initialize();
    mpu.setFullScaleGyroRange(MPU6050_GYRO_FS_250);  // ±250°/s
    mpu.setFullScaleAccelRange(MPU6050_ACCEL_FS_2);   // ±2g
}

void loop() {
    int16_t ax, ay, az, gx, gy, gz;
    mpu.getMotion6(&ax, &ay, &az, &gx, &gy, &gz);
    
    // 转换为物理单位
    float accX = ax / 16384.0;     // g
    float gyroZ = gz / 131.0;      // °/s
    
    // 互补滤波估算倾角
    static float angle = 0;
    float dt = 0.01;
    float accAngle = atan2(ay, az) * 180 / PI;  // 加速度计倾角
    angle = 0.98 * (angle + gyroZ * dt) + 0.02 * accAngle;
}
```

### 互补滤波 vs 卡尔曼滤波

| 方法 | 复杂度 | 效果 | 适用 |
|------|:--:|------|------|
| **互补滤波** | 极低 | 够用，参数简单 | L1-L3 小车 |
| **卡尔曼滤波** | 中等 | 最优估计 | L4 需要精确定位 |
| **Mahony/Madgwick** | 低 | 3D 姿态好 | 需要完整姿态 |

> 小车不需要精确 3D 姿态，互补滤波足够。重点取 `gyroZ`（偏航角速度）做转弯补偿。

## 四、多传感器时间同步

### 问题

不同传感器采样频率不同，数据到达时间不同：

| 传感器 | 频率 | 延迟 |
|--------|:--:|:--:|
| 摄像头 | 30Hz | ~33ms |
| 超声波 | 10-20Hz | ~30ms |
| IMU | 100-200Hz | ~1ms |
| 编码器 | 100Hz+ | ~1ms |
| 串口指令 | 50Hz | ~10ms |

### 策略：以最慢传感器为主时钟

```python
import time
from collections import deque

class SensorFusion:
    def __init__(self):
        self.camera_data = deque(maxlen=5)
        self.ultrasonic_data = None
        self.imu_data = deque(maxlen=20)
        self.encoder_data = deque(maxlen=20)
    
    def update(self):
        """主循环 30Hz（与摄像头同步）"""
        frame = self.get_camera()         # 33ms
        self.ultrasonic_data = self.get_ultrasonic()  # 最新值
        imu_batch = list(self.imu_data)   # 取 buffer 里的所有 IMU 数据
        encoder_batch = list(self.encoder_data)
        
        # 融合：用 IMU 修正编码器里程计
        # 用超声波确认相机检测到的障碍物距离
        
        return self.make_decision(frame, imu_batch, encoder_batch, self.ultrasonic_data)
```

### 简单融合案例：超声波校验相机

```python
def obstacle_check(camera_dist_est, ultrasonic_dist):
    """
    如果相机和超声波估计的距离差 > 30%，以超声波为准（相机可能误检）
    """
    if ultrasonic_dist > 500:  # 超声波没检测到（超量程）
        return camera_dist_est
    
    diff = abs(camera_dist_est - ultrasonic_dist) / max(camera_dist_est, 1)
    if diff > 0.3:
        return ultrasonic_dist  # 超声波更可靠
    return (camera_dist_est + ultrasonic_dist) / 2  # 加权平均
```

> 💡 这对应你笔记 [[多传感器融合基础]] 中的"异质传感器互补"。在真实 L4 系统里这是前融合/后融合问题；在小车上，简单的 rule-based 融合就够。

## 五、编码器里程计

### 从编码器脉冲推算位移

```
编码器脉冲数 N → 车轮转过的圈数 R = N / (编码器线数 × 减速比)
行驶距离 D = R × π × 轮径

例：13 线编码器，1:30 减速比 → 390 脉冲/圈
    轮径 65mm → 周长 = π × 65 ≈ 204mm
    收到 3900 脉冲 → 10 圈 → 10 × 204 = 2.04m
```

```python
class Odometer:
    def __init__(self, pulses_per_rev, wheel_diameter_mm):
        self.ppr = pulses_per_rev          # 每圈脉冲数
        self.circumference = math.pi * wheel_diameter_mm / 1000.0  # 米
    
    def pulses_to_meters(self, pulses):
        return (pulses / self.ppr) * self.circumference
```
