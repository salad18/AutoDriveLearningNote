# 🚀 模型部署

> 训练完模型只是 30% 的工作。部署到小车上实时推理，是剩下的 70%。

---

## 一、训练 vs 部署的差距

| | 训练环境 | 小车部署环境 |
|------|------|------|
| **硬件** | A100 / 4090 | Jetson Nano / Orin / Raspberry Pi |
| **算力** | 300+ TFLOPS | 0.5 ~ 40 TOPs |
| **内存** | 24GB+ VRAM | 4~8GB 共享内存 |
| **功耗** | 不关心 | 必须 <15W（电池供电） |
| **精度** | FP32 | FP16 / INT8 |
| **框架** | PyTorch | TensorRT / ONNX Runtime / TFLite |
| **延迟要求** | 不关心 | <50ms（否则撞墙） |

---

## 二、模型轻量化策略

### 策略 1：直接用小模型

| 模型 | 参数量 | 推理速度(Jetson Nano) | 精度 | 用途 |
|------|:--:|:--:|:--:|------|
| MobileNetV3-Small | 2.5M | ~8ms | 67% top-1 | 分类/特征提取 |
| EfficientNet-B0 | 5.3M | ~15ms | 77% | 分类 |
| YOLOv5n | 1.9M | ~30ms | 28% mAP | 目标检测 |
| YOLOv8n | 3.2M | ~35ms | 37% mAP | 目标检测 |
| NanoDet-Plus | 1.1M | ~20ms | 27% mAP | 目标检测 |
| ERFNet | 2.1M | ~25ms | 72% mIoU | 语义分割（车道线） |

### 策略 2：知识蒸馏

用大模型（Teacher）教小模型（Student），小模型也能有接近大模型的精度。

```
Teacher: ResNet-50 (25M) — 精度 80%, 推理 80ms
    ↓ 蒸馏（用 Teacher 的 soft label 训练 Student）
Student: MobileNetV3 (2.5M) — 精度 76%, 推理 8ms
```

### 策略 3：量化

| 精度 | 模型大小 | 推理速度 | 精度损失 | 适用 |
|:--:|:--:|:--:|:--:|------|
| FP32 | 1× | 1× | — | 训练 |
| FP16 | 0.5× | 1.5-2× | <0.5% | Jetson (推荐) |
| INT8 | 0.25× | 2-4× | 1-3% | Jetson (激进) |
| INT4 | 0.125× | 3-5× | 3-8% | 极端场景 |

### 策略 4：剪枝

移除不重要的权重/通道 → 模型更小更快。

## 三、PyTorch → ONNX

### 导出

```python
import torch

# 假设你有一个训练好的模型
model = MyLaneDetectionModel()
model.load_state_dict(torch.load('best_model.pth'))
model.eval()

# 导出 ONNX
dummy_input = torch.randn(1, 3, 224, 224)  # 批次大小1很重要
torch.onnx.export(
    model,
    dummy_input,
    'model.onnx',
    input_names=['input'],
    output_names=['output'],
    dynamic_axes={'input': {0: 'batch'}, 'output': {0: 'batch'}},
    opset_version=12  # JetPack 5.x 支持 opset 12-17
)

# 验证 ONNX 模型
import onnx
onnx_model = onnx.load('model.onnx')
onnx.checker.check_model(onnx_model)
print("ONNX export OK")
```

### ONNX Runtime 推理（CPU / 轻量 GPU）

## 四、TensorRT（Jetson 核心技能）

TensorRT 是 NVIDIA 的推理优化引擎，在 Jetson 上必备：

### FP16 优化

```python
import tensorrt as trt
import pycuda.driver as cuda
import pycuda.autoinit

# === 方法 1: trtexec (命令行，最简单) ===
# trtexec --onnx=model.onnx \
#         --fp16 \
#         --saveEngine=model_fp16.trt \
#         --workspace=2048

# === 方法 2: Python API ===
def build_engine(onnx_path, fp16=True):
    logger = trt.Logger(trt.Logger.WARNING)
    builder = trt.Builder(logger)
    network = builder.create_network(
        1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))
    parser = trt.OnnxParser(network, logger)
    
    with open(onnx_path, 'rb') as f:
        parser.parse(f.read())
    
    config = builder.create_builder_config()
    config.max_workspace_size = 1 << 30  # 1GB
    if fp16:
        config.set_flag(trt.BuilderFlag.FP16)
    
    engine = builder.build_engine(network, config)
    return engine

# 保存 engine
engine = build_engine('model.onnx', fp16=True)
with open('model_fp16.trt', 'wb') as f:
    f.write(engine.serialize())
```

### TensorRT 推理

```python
class TRTInference:
    def __init__(self, engine_path):
        self.logger = trt.Logger(trt.Logger.WARNING)
        with open(engine_path, 'rb') as f, trt.Runtime(self.logger) as runtime:
            self.engine = runtime.deserialize_cuda_engine(f.read())
        self.context = self.engine.create_execution_context()
        
        # 分配显存
        self.inputs, self.outputs, self.bindings = [], [], []
        for binding in self.engine:
            shape = self.engine.get_binding_shape(binding)
            size = trt.volume(shape) * self.engine.get_binding_dtype(binding).itemsize
            d_mem = cuda.mem_alloc(size)
            self.bindings.append(int(d_mem))
            if self.engine.binding_is_input(binding):
                self.inputs.append({'name': binding, 'device': d_mem, 'shape': shape})
            else:
                self.outputs.append({'name': binding, 'device': d_mem, 'shape': shape,
                                     'host': cuda.pagelocked_empty(shape, dtype=np.float32)})
    
    def infer(self, input_data):
        # 拷贝输入到 GPU
        cuda.memcpy_htod(self.inputs[0]['device'], input_data.ravel())
        
        # 推理
        self.context.execute_v2(self.bindings)
        
        # 拷贝输出到 CPU
        for o in self.outputs:
            cuda.memcpy_dtoh(o['host'], o['device'])
        
        return [o['host'].reshape(o['shape']) for o in self.outputs]

# 使用
trt_model = TRTInference('model_fp16.trt')
result = trt_model.infer(np.random.randn(1, 3, 224, 224).astype(np.float32))
```

## 五、端到端推理管线

```python
class CarInferencePipeline:
    """
    完整的推理管线：图像 → 模型 → 控制指令
    """
    def __init__(self, model_path, serial_port):
        self.model = TRTInference(model_path)
        self.ser = serial.Serial(serial_port, 115200)
        self.cap = cv2.VideoCapture(0)
        
        # 预处理参数（必须和训练时一致！）
        self.mean = np.array([0.485, 0.456, 0.406])
        self.std = np.array([0.229, 0.224, 0.225])
        self.input_size = (224, 224)
    
    def preprocess(self, frame):
        """与训练时保持完全一致的预处理"""
        img = cv2.resize(frame, self.input_size)
        img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
        img = img.astype(np.float32) / 255.0
        img = (img - self.mean) / self.std
        img = np.transpose(img, (2, 0, 1))  # HWC → CHW
        return np.expand_dims(img, axis=0)    # → NCHW
    
    def postprocess(self, output):
        """模型输出 → 控制指令"""
        # 假设模型输出 [steering, throttle]
        steering = float(output[0][0])
        throttle = float(output[0][1])
        
        # 映射到实际范围
        steer_angle = int(90 + steering * 40)  # 90±40
        throttle_pwm = int(throttle * 150 + 105)  # 105~255
        
        return max(50, min(130, steer_angle)), max(0, min(255, throttle_pwm))
    
    def run(self):
        try:
            while True:
                ret, frame = self.cap.read()
                if not ret: continue
                
                # 推理
                tensor = self.preprocess(frame)
                output = self.model.infer(tensor)
                
                # 控制
                steer, throttle = self.postprocess(output)
                cmd = f"S{steer}T{throttle}\n"
                self.ser.write(cmd.encode())
                
                # 监控延迟
                t = time.time()
                # print(f"Inference: {(time.time()-t)*1000:.1f}ms")
        finally:
            motor_stop()
```

## 六、常见部署坑

| 坑 | 现象 | 解决 |
|----|------|------|
| **预处理不一致** | 训练正常，部署完全不对 | 导出预处理为 ONNX 的一部分，或用脚本确保一致性 |
| **RGB/BGR 搞反** | 检测结果混乱 | OpenCV 默认 BGR，训练通常是 RGB |
| **动态 batch size** | TensorRT 报错 | 导出 ONNX 时固定 batch=1 |
| **算子不支持** | ONNX→TensorRT 转换失败 | 检查 opset 版本，替换不支持的算子 |
| **精度损失太大** | INT8 推理不准 | 先用 FP16；INT8 需要校准数据集 |
| **Jetson 过热降频** | 推理忽快忽慢 | 加强散热，降低功耗模式 |
