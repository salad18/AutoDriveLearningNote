## 〇、大白话总览

### 小车 = 四个部分的组合

```
① 底盘与驱动（车架/电机/舵机）  → 让车能走
② 主控制器（Arduino/Pi/Jetson） → 让车有"脑子"
③ 传感器（红外/摄像头/IMU）    → 让车有"眼睛"
④ 电源系统（电池/降压）        → 让车有"能量"
```

> [!note] 打个比方
> 组装小车像**配电脑**：底盘 = 机箱电源（基础）、主控 = CPU（算力分档）、传感器 = 外设（按需加）、电池 = 供电（功率匹配）。**"主控的算力"决定小车"能到 L 几"**——这是选型的第一原则。

### 选型的核心原则（先记住）

```
预算跟着级别走（L0-L4 逐级买）
算力跟着任务走（L0 控制 → L4 AI 推理）
供电跟着功耗走（电机大电流 + 主控稳定 5V）
```

## 一、底盘与驱动

### RC 车架

| 类型 | 价格 | 优点 | 缺点 | 推荐场景 |
|------|:--:|------|------|----------|
| **1:16 RC 攀爬车** | ¥150-300 | 自带电机+舵机+悬挂，结实 | 速度慢，体积大 | L0-L2 入门首选 |
| **1:10 平跑车架** | ¥200-400 | 速度快，操控好 | 需要自己配电子设备 | L2-L4 进阶 |
| **铝合金底盘套件** | ¥100-200 | 可扩展性强 | 需要自己组装一切 | 喜欢折腾 |
| **Donkey Car 套件** | ¥800-1500 | 专为 AI 小车设计，社区活跃 | 贵，进口 | L3-L4 省心方案 |

**推荐**：淘宝搜 "1:16 RC 攀爬车架 金属传动" → ¥200 左右，到手即用。

> [!note] 为什么 L0-L2 推荐"1:16 RC 攀爬车"？
> **自带电机+舵机+悬挂 = 到手即用**（不用配电子设备）；结实耐撞（新手必摔）；速度慢 = 安全（室内练习够用）。**"到手即用 + 结实 + 慢"是入门车架的三要素**——Donkey Car 贵在"专为 AI 设计 + 社区生态"（L3-L4 省心）。

### 电机类型

| 类型 | 控制方式 | 速度反馈 | 适用场景 |
|------|----------|:--:|------|
| **直流有刷电机** | PWM 调速 | 无（需外加编码器） | L0-L2 |
| **直流无刷电机** | 电调(ESC) PWM | 无 | L3+ 需要速度 |
| **步进电机** | 脉冲控制 | 开环精确 | 机械臂，不适合小车 |
| **带编码器的减速电机** | PWM + 编码器读数 | ✅ | L3+ 精确里程计 |

**推荐**：L0-L2 用 **TT 减速电机** 或车架自带电机；L3+ 换 **带霍尔编码器的 JGA25-370 电机**（¥30/个）。

> [!warning] 编码器电机为什么 L3 才需要？（面试/选型谈资）
> **编码器 = 电机的"里程表"**（读转数 → 算里程/速度）。L0-L2 循迹避障不需要精确里程（红外+超声波够）；**L3+ 要做 SLAM/里程计（[[SLAM与定位]]）必须知道"车走了多远"**——编码器是里程计的硬件基础。**"传感器跟着任务走"的又一例证。**

## 二、主控制器

| 主控 | 价格 | 算力 | 功耗 | 适合阶段 | 能跑什么 |
|------|:--:|------|------|:--:|------|
| **Arduino Uno R3** | ¥30 | 16MHz MCU | <1W | L0-L1 | PID 控制、传感器读取、PWM |
| **Arduino Mega 2560** | ¥60 | 16MHz MCU | <2W | L1-L2 | 更多 IO、多串口 |
| **ESP32** | ¥25 | 240MHz 双核+WiFi/BT | <2W | L1-L2 | WiFi 图传、简单 CV |
| **Raspberry Pi 4B (4G)** | ¥400 | 4核 A72 1.8GHz | 5-10W | L2-L3 | OpenCV、轻量 CNN |
| **Raspberry Pi 5 (8G)** | ¥550 | 4核 A76 2.4GHz | 8-15W | L2-L4 | 更快的推理 |
| **Jetson Nano 4G** | ¥800 | 128核 GPU | 5-10W | L3 | YOLO 实时、ResNet |
| **Jetson Orin Nano 8G** | ¥2500 | 1024核 GPU+16T DLA | 7-15W | L3-L4 | Transformer、BEV |

> [!note] 主控的"算力分档"（选型第一原则）
> - **MCU 级（Arduino/ESP32，¥25-60）**：L0-L2 控制（PWM/PID/传感器）——**实时性好、功耗低，但跑不了 AI**。
> - **SBC 级（树莓派，¥400-550）**：L2-L3 视觉（OpenCV/轻量 CNN）——**能跑 Linux + Python，AI 入门**。
> - **NPU 级（Jetson，¥800-2500）**：L3-L4 AI 推理（YOLO/Transformer/BEV）——**有 GPU/NPU，真 AI**。
> **"算力分档"和 [[小车项目总览]] 的 L0-L4 一一对应**——每级买对应算力的主控。

### 组合方案

```
┌─ L0-L1 方案 ─────────────────────┐
│ Arduino Uno (底层控制)              │
│   ├── 电机 PWM                      │
│   ├── 舵机控制                      │
│   ├── 红外/超声波读取                │
│   └── HC-05 蓝牙 ← 手机遥控         │
└──────────────────────────────────┘

┌─ L2 方案 ────────────────────────┐
│ Raspberry Pi 4B (上层视觉)          │
│   ├── USB 摄像头 → OpenCV           │
│   └── 串口 → Arduino Uno (底层)     │
│                                      │
│ Arduino Uno (底层控制)               │
│   └── 接收 Pi 指令 → 执行           │
└──────────────────────────────────┘

┌─ L3-L4 方案 ─────────────────────┐
│ Jetson Orin Nano (AI 推理)          │
│   ├── 多摄像头 → 模型推理            │
│   └── 串口/USB → Arduino/ESP32      │
│                                      │
│ Arduino Mega (底层+传感器)           │
│   ├── 电机/舵机控制                  │
│   ├── 编码器/IMU 读数                │
│   └── 超声波紧急刹车                 │
└──────────────────────────────────┘
```

> [!warning] "双主控"架构 = 量产车的分层（重要认知）
> L2 起用"**上层主控（Pi/Jetson 做视觉/AI）+ 底层主控（Arduino 做控制）**"双主控——**和量产车"域控制器 + MCU"分层一模一样**（[[小车项目总览]] 的五层架构）：慢速复杂计算（AI）在主机，快速低层控制（PWM）在单片机。**你在小车上搭的分层架构 = 量产车架构的缩小版**。

> 💡 **省钱技巧**：L2-L3 阶段把笔记本放地上，USB 延长线接摄像头，WiFi 连小车——省了树莓派和 Jetson 的钱。

## 四、电源系统

| 组件 | 推荐型号 | 价格 | 说明 |
|------|------|:--:|------|
| **锂电池** | 7.4V 2200mAh 2S Lipo | ¥50 | 电机供电 |
| **锂电池** | 11.1V 2200mAh 3S Lipo | ¥70 | Jetson 供电 |
| **充电器** | B6AC 平衡充 | ¥80 | 必备，不要省 |
| **降压模块** | LM2596 / Mini560 | ¥5-15 | 将 7.4V/11.1V 降到 5V |
| **电压显示器** | 2S-6S BB 响 | ¥10 | 防过放，保护电池 |

### 供电架构

```
11.1V Lipo (3S)
  ├──→ 电机驱动 (直供)
  ├──→ LM2596 降压 → 5V → Arduino / 舵机 / 传感器
  └──→ 另路 5V 降压 → Raspberry Pi / Jetson (需稳定 5V 3A+)
```

> ⚠️ **安全警告**：锂电池过放（<3.3V/节）会永久损坏。一定接 BB 响！充电时人在旁边看着。

> [!warning] 供电架构的"为什么"（工程思维）
> ① **电机直供电池**（电机电流大，走降压会拖垮 5V）；② **主控/传感器单独降压**（Arduino 5V 和 Pi 5V 3A 分开——**Pi/Jetson 对电压敏感，电机启停的电压波动会重启它**）。**"大电流设备直供、敏感设备稳压"是供电设计的铁律**——这个经验在 [[底盘与电机控制]] 的调试里会反复遇到。

## 七、常见误区速查

> [!warning] 选型最常踩的坑
> 1. **一步到位买 Jetson**——L0-L2 用不上，吃灰率 90%；**预算跟着级别走**。
> 2. **买"Arduino 学习套件"**——一堆用不上的模块；**按需零买**（本指南的预算表就是清单）。
> 3. **主控和电机不匹配**——L4 用 Arduino 控车（算力不够）、L0 用 Jetson（浪费）——**算力跟着任务走**。
> 4. **供电偷懒**——电机和主控共用一路 5V → 电机一启动主控重启；**大电流直供、敏感设备稳压**。
> 5. **电池不接 BB 响**——锂电池过放永久损坏；**BB 响 ¥10 是保险**。

## ✅ 检验自己（自测题）

> [!question] Q1：L0-L4 各自的主控选什么？为什么？
> 提示：算力分档。

> [!success]- 参考答案
> L0-L1：Arduino Uno（MCU，PWM/PID 控制，实时性好功耗低）；L2-L3：树莓派（SBC，OpenCV/轻量 CNN）；L3-L4：Jetson（NPU，YOLO/Transformer/BEV）。逻辑：算力跟着任务走——L0 只要控制（MCU 够），L4 要 AI 推理（必须 NPU）。"主控的算力"决定小车"能到 L 几"。

> [!question] Q2：为什么 L2 起要用"双主控"（Pi/Jetson + Arduino）？
> 提示：分层架构。

> [!success]- 参考答案
> 上层主控（Pi/Jetson）做视觉/AI（慢速复杂计算），底层主控（Arduino）做控制（快速低层 PWM/PID）——和量产车"域控制器 + MCU"分层一致（[[小车项目总览]] 五层架构）。分工逻辑：AI 推理不需要每毫秒响应（放主机），PWM 控制必须实时（放单片机）。小车的双主控 = 量产车架构的缩小版。

> [!question] Q3：为什么编码器电机 L3 才需要？IMU 装在哪、为什么？
> 提示：里程计/姿态参考。

> [!success]- 参考答案
> 编码器 = 电机的"里程表"（读转数算里程/速度）——L0-L2 循迹避障不需要精确里程，L3+ 做 SLAM/里程计（[[SLAM与定位]]）必须知道"车走了多远"。IMU 装在车中心（姿态/角速度参考），摄像头在前（看路）、超声波在前角（避障）、红外在底盘下（看地面线）——传感器装在最能感知对应信息的位置（外参概念雏形）。

> [!question] Q4：供电架构为什么"电机直供电池、主控单独稳压"？
> 提示：大电流/敏感设备。

> [!success]- 参考答案
> ① 电机电流大（启停瞬态电流可达数 A），走降压会拖垮 5V 线路；② Pi/Jetson 对电压敏感，电机启停的电压波动会重启主控。所以：**大电流设备（电机）直供电池，敏感设备（主控/传感器）单独稳压**——供电设计铁律，也是 [[底盘与电机控制]] 调试里"主控莫名重启"的头号排查点。

> [!question] Q5：L0-L4 的总预算大概多少？"预算跟着级别走"为什么重要？
> 提示：250/400/900/1900+。

> [!success]- 参考答案
> L0 约 ¥250-350、L1 +¥50、L2 +¥500、L3 +¥1000-3500——**总计约 ¥2000-4500 按需追加**。"预算跟着级别走"重要：① 避免一步到位买 Jetson 吃灰；② 每级硬件是下一级的前置（L0 底盘是 L4 的底）；③ 把预算花在"当前级别的刚需"上，不会浪费。

### 练习 1：给自己配一套 L0 套餐（20 分钟）

按第五节 L0 套餐，去淘宝搜一遍，记录：
1. 每个物品的实际价格（L0 套餐总价是否在 ¥200-350 区间？）
2. 找 2 个"评论里反馈质量差"的坑（比如便宜电机虚标）。
3. 写一份你的"L0 下单清单"（含链接备选）。

> [!tip] 这是"动手前必做"的练习
> 先搜价再下单，能省 30% 预算（很多模块价格差 2-3 倍）。**"预算表 + 实际搜价"才是真预算**。

### 练习 2：画"小车 = 量产车"硬件对照表（30 分钟）

用 Excalidraw 画对照表：
| 小车硬件 | 量产车对应 | 对应笔记 |
|----------|-----------|----------|
| Arduino | 车规 MCU | [[底盘与电机控制]] |
| 摄像头+超声波 | Camera + Radar | [[多传感器融合基础]] |
| Jetson | 域控制器 | [[模型部署]] |
| 编码器+IMU | 里程计+IMU | [[SLAM与定位]] |

> [!tip] 画完自问
> ① 小车缺了量产车的哪些硬件？（LiDAR/高精地图——为什么可以缺？）② 这套对照表在面试"你做过什么"时怎么用？（"我做的双主控小车 = 域控制器+MCU 分层"）

### 练习 3：写"L0 到货检查清单"（可选，20 分钟）

写一份 L0 到货后 10 分钟检查清单：
1. 供电：电池电压、BB 响是否响。
2. 主控：Arduino 灯亮、上传 Blink 成功。
3. 电机：PWM 测试轮子转。
4. 蓝牙：手机连 HC-05。
5. 传感器：红外/超声波读数正常。

> [!tip] 到货检查 = 排错前置
> 先验证"每个零件单独能工作"，再组装——不然"全装好了不转"根本不知道哪坏了。这份清单配合 [[底盘与电机控制]] 使用。
