# 🔧 硬件选型指南

> 从零到自动驾驶小车，每一级需要买什么、多少钱、怎么选。

---

## 一、底盘与驱动

### RC 车架

| 类型 | 价格 | 优点 | 缺点 | 推荐场景 |
|------|:--:|------|------|----------|
| **1:16 RC 攀爬车** | ¥150-300 | 自带电机+舵机+悬挂，结实 | 速度慢，体积大 | L0-L2 入门首选 |
| **1:10 平跑车架** | ¥200-400 | 速度快，操控好 | 需要自己配电子设备 | L2-L4 进阶 |
| **铝合金底盘套件** | ¥100-200 | 可扩展性强 | 需要自己组装一切 | 喜欢折腾 |
| **Donkey Car 套件** | ¥800-1500 | 专为 AI 小车设计，社区活跃 | 贵，进口 | L3-L4 省心方案 |

**推荐**：淘宝搜 "1:16 RC 攀爬车架 金属传动" → ¥200 左右，到手即用。

### 电机类型

| 类型 | 控制方式 | 速度反馈 | 适用场景 |
|------|----------|:--:|------|
| **直流有刷电机** | PWM 调速 | 无（需外加编码器） | L0-L2 |
| **直流无刷电机** | 电调(ESC) PWM | 无 | L3+ 需要速度 |
| **步进电机** | 脉冲控制 | 开环精确 | 机械臂，不适合小车 |
| **带编码器的减速电机** | PWM + 编码器读数 | ✅ | L3+ 精确里程计 |

**推荐**：L0-L2 用 **TT 减速电机** 或车架自带电机；L3+ 换 **带霍尔编码器的 JGA25-370 电机**（¥30/个）。

|------|:--:|------|------|:--:|------|

| **Arduino Mega 2560** | ¥60 | 16MHz MCU | <2W | L1-L2 | 更多 IO、多串口 |

| **Raspberry Pi 4B (4G)** | ¥400 | 4核 A72 1.8GHz | 5-10W | L2-L3 | OpenCV、轻量 CNN |
| **Raspberry Pi 5 (8G)** | ¥550 | 4核 A76 2.4GHz | 8-15W | L2-L4 | 更快的推理 |

### 组合方案

```
┌─ L0-L1 方案 ─────────────────────┐
│ Arduino Uno (底层控制)              │
│   ├── 电机 PWM                      │
│   ├── 舵机控制                      │
│   ├── 红外/超声波读取                │
│   └── HC-05 蓝牙 ← 手机遥控         │
└──────────────────────────────────┘

┌─ L2 方案 ────────────────────────┐
│ Raspberry Pi 4B (上层视觉)          │
│   ├── USB 摄像头 → OpenCV           │
│   └── 串口 → Arduino Uno (底层)     │
│                                      │
│ Arduino Uno (底层控制)               │
│   └── 接收 Pi 指令 → 执行           │
└──────────────────────────────────┘

┌─ L3-L4 方案 ─────────────────────┐
│ Jetson Orin Nano (AI 推理)          │
│   ├── 多摄像头 → 模型推理            │
│   └── 串口/USB → Arduino/ESP32      │
│                                      │
│ Arduino Mega (底层+传感器)           │
│   ├── 电机/舵机控制                  │
│   ├── 编码器/IMU 读数                │
│   └── 超声波紧急刹车                 │
└──────────────────────────────────┘
```

> 💡 **省钱技巧**：L2-L3 阶段把笔记本放地上，USB 延长线接摄像头，WiFi 连小车——省了树莓派和 Jetson 的钱。

## 四、电源系统

| 组件 | 推荐型号 | 价格 | 说明 |
|------|------|:--:|------|
| **锂电池** | 7.4V 2200mAh 2S Lipo | ¥50 | 电机供电 |
| **锂电池** | 11.1V 2200mAh 3S Lipo | ¥70 | Jetson 供电 |
| **充电器** | B6AC 平衡充 | ¥80 | 必备，不要省 |
| **降压模块** | LM2596 / Mini560 | ¥5-15 | 将 7.4V/11.1V 降到 5V |
| **电压显示器** | 2S-6S BB 响 | ¥10 | 防过放，保护电池 |

### 供电架构

```
11.1V Lipo (3S)
  ├──→ 电机驱动 (直供)
  ├──→ LM2596 降压 → 5V → Arduino / 舵机 / 传感器
  └──→ 另路 5V 降压 → Raspberry Pi / Jetson (需稳定 5V 3A+)
```

> ⚠️ **安全警告**：锂电池过放（<3.3V/节）会永久损坏。一定接 BB 响！充电时人在旁边看着。
