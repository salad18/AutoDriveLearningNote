# 🧪 本地训练方案

> 基于本地硬件（AMD CPU + RX 7800 XT），从零搭建 ML 训练环境，设计可落地的感知 & 端到端实验。

---

## 一、硬件评估

| 组件 | 型号 | 训练价值 |
|------|------|:--:|
| **GPU** | AMD Radeon RX 7800 XT 16GB | ⭐⭐⭐⭐ ~RTX 4070 级，但不能用 CUDA |
| **CPU** | AMD Ryzen 5 9600X 6C/12T | ⭐⭐⭐ 单核强，适合数据预处理 |
| **RAM** | 31GB DDR5 | ⭐⭐⭐⭐ 够加载 nuScenes/KITTI 全量 |
| **磁盘** | 160GB 可用 / 1.9TB 总量 | ⭐⭐⭐ 够存所有数据集 |

### 关键约束

```
❌ 无 NVIDIA GPU → 无 CUDA
❌ ROCm 在 Windows 上基本不可用
✅ 可用 DirectML (DX12) 做 GPU 加速
✅ CPU 31GB + 12 线程 → 小模型训练完全可行
```

### GPU 使用策略

| 场景 | 方案 | 速度对比 |
|------|------|:--:|
| **训练**（PyTorch 模型） | CPU 训练 + 小模型策略 | 基准 |
| **训练**（ONNX Runtime） | DirectML EP | 3-10x CPU |
| **推理** | ONNX Runtime + DirectML | 10-50x CPU |
| **推理** | OpenVINO (Intel 优化) | 不适用 (AMD CPU) |

> 💡 **核心策略**：用 CPU 做 PyTorch 训练（灵活、兼容性好），用 ONNX Runtime DirectML 做推理加速（榨取 GPU 性能）。

**KITTI → YOLO 格式转换**：

```python
# convert_kitti_to_yolo.py
import os
from pathlib import Path

# KITTI label format: type x1 y1 x2 y2 ...
# YOLO format: class_id cx cy w h (normalized)

CLASSES = ['Car', 'Pedestrian', 'Cyclist']  # KITTI 中我们关注的
IMG_W, IMG_H = 1242, 375  # KITTI 图像尺寸

def convert_label(kitti_label_path, yolo_label_path):
    with open(kitti_label_path) as f:
        lines = f.readlines()
    
    yolo_lines = []
    for line in lines:
        parts = line.strip().split()
        obj_type = parts[0]
        if obj_type not in CLASSES:
            continue
        
        cls_id = CLASSES.index(obj_type)
        x1, y1, x2, y2 = map(float, parts[4:8])
        
        cx = ((x1 + x2) / 2) / IMG_W
        cy = ((y1 + y2) / 2) / IMG_H
        w = (x2 - x1) / IMG_W
        h = (y2 - y1) / IMG_H
        
        yolo_lines.append(f"{cls_id} {cx:.6f} {cy:.6f} {w:.6f} {h:.6f}")
    
    with open(yolo_label_path, 'w') as f:
        f.write('\n'.join(yolo_lines))

# 批量转换
for label_file in Path('D:/datasets/kitti/training/label_2').glob('*.txt'):
    convert_label(label_file, Path('labels') / label_file.name)
```

核心训练代码：

```python
# train_monodepth.py
class LiteMono(nn.Module):
    """
    轻量单目深度估计，对标 [[BEVDet与BEVDepth]] 的深度预测模块
    架构: MobileNetV2 Encoder + 轻量 Decoder
    """
    def __init__(self):
        super().__init__()
        self.encoder = torchvision.models.mobilenet_v2(pretrained=True).features
        self.decoder = DepthDecoder(num_ch_enc=[16, 24, 32, 96, 1280])
    
    def forward(self, x):
        features = []
        for i, layer in enumerate(self.encoder):
            x = layer(x)
            if i in [1, 3, 6, 13, 18]:  # 多尺度特征
                features.append(x)
        return self.decoder(features)

# 损失: L1 + SSIM + 边缘平滑
def depth_loss(pred, target):
    l1 = torch.abs(pred - target).mean()
    ssim = 1 - ssim_loss(pred, target)
    smooth = edge_smoothness(pred)
    return l1 + 0.1 * ssim + 0.001 * smooth
```

### 实验 5：简化 BEV 检测（进阶，7-10 天）

**目标**：在 CPU 上跑通 BEV 检测的最小版

```yaml
模型: SimpleBEV (极简版 BEVDet)
数据集: nuScenes mini
训练时间: ~24-48 小时 (CPU, 会很慢但能跑)
输出: BEV 3D 检测框
```

```python
# simple_bev.py — BEV 检测最小实现
class SimpleBEV(nn.Module):
    """
    简化版 BEVDet，帮助理解 [[BEVDet与BEVDepth]] 的核心流程
    
    流程:
      N 个相机图像 → ResNet 特征 → LSS 深度估计 → 投影到 BEV 
      → BEV Encoder (Conv) → 3D 检测头
    
    去掉了: 时序融合, 深度真值监督, 复杂的 BEV Encoder
    """
    def __init__(self, num_cameras=6, bev_size=(128, 128)):
        super().__init__()
        # 图像 backbone（每个相机共享）
        self.backbone = torchvision.models.resnet18(pretrained=True)
        self.backbone = nn.Sequential(*list(self.backbone.children())[:-2])
        
        # 深度估计头 (LSS 的 DepthNet)
        self.depth_head = nn.Sequential(
            nn.Conv2d(512, 256, 1), nn.ReLU(),
            nn.Conv2d(256, 64, 1),    # 64 = 深度 bin 数
        )
        
        # BEV Encoder
        self.bev_encoder = nn.Sequential(
            nn.Conv2d(512, 256, 3, padding=1), nn.BatchNorm2d(256), nn.ReLU(),
            nn.Conv2d(256, 128, 3, padding=1), nn.BatchNorm2d(128), nn.ReLU(),
        )
        
        # 检测头（简化版 CenterPoint）
        self.heatmap_head = nn.Conv2d(128, 3, 1)  # 3 类: Car, Ped, Cyc
        self.reg_head = nn.Conv2d(128, 2, 1)       # dx, dy offset
    
    def forward(self, images):
        # images: (B, N_cam, 3, H, W)
        B, N, C, H, W = images.shape
        
        # 1. 每个相机提取特征 + 深度
        features = []
        depths = []
        for i in range(N):
            feat = self.backbone(images[:, i])          # (B, 512, H/32, W/32)
            depth = self.depth_head(feat).softmax(dim=1) # (B, 64, H/32, W/32)
            features.append(feat)
            depths.append(depth)
        
        # 2. LSS: 特征 × 深度 → 3D Frustum → Voxel Pooling → BEV
        bev_feat = self.lss_project(features, depths)  # 见 [[BEVDet与BEVDepth]]
        
        # 3. BEV Encoder + 检测头
        bev_feat = self.bev_encoder(bev_feat)
        heatmap = self.heatmap_head(bev_feat)
        offset = self.reg_head(bev_feat)
        
        return heatmap, offset
```

> ⚠️ 这个实验在 CPU 上训练非常慢（~48h+），建议只在理解了 [[BEVDet与BEVDepth]] 后，用于验证理解，不要作为主要实验。

# 当 batch=4 显存不够时，累积梯度模拟 batch=16
