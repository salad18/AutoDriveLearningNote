# 华为 ADS 端到端架构：GOD + PDP

> ADS 3.0 的端到端哲学：感知一张网 (GOD)，规划一张网 (PDP)，各司其职，联合优化。

---

## 一、为什么是"分体式端到端"

### 感知规划分离 vs 大一统

```
特斯拉思路:     感知 ─────────→ 规划 ─────────→ 控制
               └────────── 一个超大模型 ──────────┘

华为思路:      感知 (GOD大网) ──→ 规划 (PDP网络)
               └──── 两个网络, 端到端联合优化 ────┘
```

**华为选择分体式的原因**：

| 维度 | 大一统模型 | GOD+PDP 分体式 |
|------|-----------|---------------|
| **可解释性** | 差（黑盒） | 好（感知结果可审计） |
| **调试** | 难（无法定位问题模块） | 模块化调试 |
| **安全验证** | 困难 | 感知独立验证 |
| **迭代速度** | 整体耦合 | 模块独立迭代 |
| **冗余** | 无 | 感知输出有多重验证 |

> 华为认为：汽车安全是底线，不可解释的端到端黑盒对安全验证是灾难。

### 软关联融合机制

华为 GOD 的关键创新：用 Transformer 的 Cross-Attention 替代硬关联 (硬标定对齐)。

```
传统硬关联:
  LiDAR 点 ←→ Camera 像素 精确对齐 (标定要求极高)
  → 一旦标定漂移, 融合失效

华为软关联:
  LiDAR 点特征 → Transformer Cross-Attention → 自适应寻找对应的图像特征
  → 不需要像素级对齐, 模型自己学习对应关系
```

**论文背景**：2022 年华为与港科大、港城大合作论文中描述了类似 TransFusion 的方法：
1. LiDAR 点云 → 初步 3D 特征/边界框
2. 将 3D 信息投影到 2D 图像 → 融合语义特征
3. 高分辨率图像 → Cross-Attention 增强小目标检测

### GOD 的核心能力阶梯

```
Level 1: 白名单目标检测      (ADS 1.0 的 BEV)
Level 2: 异形障碍物检测      (ADS 2.0 加入 GOD)
Level 3: 占据空间理解        (像 Tesla OccNet)
Level 4: 场景语义理解        (ADS 3.0: "理解"而不仅是"看到")
Level 5: 行为预判            (在感知阶段预判其他 agent 下一步动作)
```

### PDP 的训练

```
训练数据源:
1. 人类驾驶数据 (量产车采集)
   → 模仿学习: 你的变道时机、跟车距离
2. 仿真驾驶数据 (云端 3500 万 km/天)
   → 强化学习: 在仿真中探索极端场景
3. 影子模式数据
   → 比对: 人类实际驾驶 vs 模型预测

训练方式:
  Stage 1: 预训练 (模仿人类驾驶)   ← 学习"像人一样开"
  Stage 2: 强化学习微调            ← 安全 + 效率
  Stage 3: CAS 3.0 安全约束       ← 最后的安全兜底
```

### PDP 为什么更类人

| 传统规则规划 | PDP 网络 |
|-------------|----------|
| "如果前车 30m 内 → 减速" | 学习人类真实的跟车距离分布 |
| 固定换道时机 | 根据场景动态决策 |
| 路口逻辑写死 | 通过大量路口数据学会"怎么过" |
| 保守到影响效率 | 类人平衡安全与效率 |

## 四、CAS 3.0 — 安全兜底

PDP 规划 + CAS 3.0 安全层 → **双重保障**。

```
PDP 规划输出
     ↓
CAS 3.0 安全检查
     ↓
  ┌─ 通过 → 执行
  │
  └─ 冲突 → 安全干预 (减速/转向/刹停)
```

CAS 3.0 不是模型，而是基于物理约束和确定性规则的安全兜底。这解决了纯端到端模型的最核心问题：**任何模型都可能出错，必须有一层"物理定律"兜底**。

## 六、关键洞察

### 华为 ADS 3.0 的技术选择逻辑

```
为什么保留 LiDAR？
  → 纯视觉 2D→3D 升维计算量巨大
  → LiDAR 提供"免费"的 3D 信息
  → 全天候能力 (雨雾/黑夜/大光比)
  → 降低了云端算力需求 (不用花大算力把2D升成3D)

为什么分离 GOD 和 PDP？
  → 安全审计：感知错了还是规划错了？可定位
  → 独立迭代：感知提升不需要改规划
  → 规则兜底：CAS 3.0 可以在感知输出上做安全验证

为什么 200 TOPS 够用？
  → 算法优化：软关联替代硬标定，减少计算
  → 感知降维：LiDAR 提供 3D 先验，不需要从 2D 费力还原
  → 任务聚焦：不做大一统，每个网络专精
```
