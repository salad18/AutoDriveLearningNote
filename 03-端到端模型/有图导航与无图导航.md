# 有图导航与无图导航

> 一句话导读："有图"靠**高精地图**（提前画好的厘米级地图），"无图"靠**实时感知+在线建图**（车自己"画"地图）——**但"无图"不是真的不用地图**。本篇讲透有图/无图/轻图的本质区别、华为/特斯拉/Momenta 的主流方案，以及面试怎么答"你们是无图方案吗"。

## 〇、大白话总览

### 一个比喻：导航地图的三种形态

```
有图（高精地图）:  "拿着施工图纸开车"——路况提前画好（厘米级），但图纸会过时、覆盖不全
无图:            "边开边记路"——不拿图纸，用眼睛（感知）+ 脑子（模型）实时理解路况
轻图:            "拿张草图开车"——只有大概路线（导航地图），细节靠眼睛实时看
```

**核心结论（先记住）**：**"无图"不是"不用地图"，而是"不用高精地图"**——车仍然用普通导航地图（知道去哪）+ 实时感知/在线建图（理解路况）。**地图从"提前画的"变成"实时画的"。**

> [!note] 为什么这个话题重要？
> ① 面试高频："你们是无图方案吗？""无图和有图本质区别？"——量产智驾面试必问。
> ② 华为 ADS 3.0 宣传"无图全国可用"——"无图"是 2024-2026 量产智驾的最大卖点。
> ③ 它串起了 [[华为ADS技术方案]]（RCR）、[[多传感器融合基础]]（感知兜底）、[[端到端自动驾驶概览]]（规划输入）——本库的多篇笔记。

## 一、有图导航：高精地图（HD Map）

### 1.1 什么是高精地图

```
高精地图 (HD Map / 高精度地图):
  精度: 厘米级（±10cm）| 要素: 车道级（车道线/路沿/交通标志/拓扑/坡度曲率）
  来源: 专业采集车 + 人工标注 + 定期更新
  定位: 为自动驾驶"量身定制"的地图（比导航地图精细得多）
```

**HD Map 的三层内容**：
1. **道路模型**：车道几何（中心线、边界、曲率）、路口拓扑。
2. **车道属性**：限速、转向规则、路权（谁让谁）。
3. **定位辅助**：车道级定位（车在哪条车道）。

### 1.2 有图的优点与致命缺点

| 维度 | 优点 | 缺点 |
|------|------|------|
| **精度** | 厘米级先验，感知压力小 | 采集/标注成本极高 |
| **覆盖** | 采集过的区域很准 | **覆盖不全**（没采到的地方不能用） |
| **更新** | 定期更新 | **会过期**（施工/改线后地图失效）|
| **成本** | — | 高精地图采集一辆车一天几十万 |

> [!warning] 有图方案的"死穴"（为什么大家都在去图化）
> ① **覆盖**：高精地图只覆盖采集过的城市/道路——"有图才能开，无图不能开"；② **时效**：道路改了（施工围挡、重新划线），地图还是旧的 → 车按旧图开 = 危险；③ **成本**：全国高精地图采集维护是天量投入。**"有图"能做好"点"（采过的区域），做不好"面"（全国）。**

## 二、无图导航：无图智驾

### 2.1 "无图"的真相（最重要！）

```
"无图"不是不用地图，而是:
  ① 不用高精地图（厘米级、预采集）
  ② 仍用普通导航地图（SD Map，米级，知道"去哪"）
  ③ 路况细节靠"实时感知 + 在线建图"（车自己理解车道/路口）
```

> 参考："无图"盛行时代，智驾依然离不开地图（[第一电动](https://www.d1ev.com/kol/277371)）——**行业共识：无图智驾仍依赖基础导航地图 + 实时建图**。

### 2.2 无图的实现：感知替代地图

```
无图方案的技术链:
  导航地图（去哪）→ 实时感知（车道线/路沿/红绿灯）→ 在线建图（拼接成"实时地图"）
                     ↑ 靠什么？BEV 感知 + 语义建图 + 记忆建图（[[BEV感知全景]] 的感知家族）
```

**无图对能力的要求（比有图高）**：
| 能力 | 为什么需要 |
|------|-----------|
| **车道线/路沿感知** | 车道在哪要靠看（BEV 语义分割）|
| **路口拓扑理解** | 路口怎么连要靠模型推理（RCR 的道路认知）|
| **长时记忆** | 同一路段反复走，记住"上次的感知结果"（记忆建图）|
| **强传感器** | 感知压力大 → 需要更好的相机/LiDAR（[[多传感器融合基础]]）|

> [!note] "无图"的本质 = **用模型/传感器替代地图先验**
> 有图：地图告诉你"前方 200 米是左转车道"（先验）。
> 无图：模型看到"前方车道线变虚线 + 地面箭头"→ 推理"这是左转车道"（实时）。
> **"先验换实时"的代价**：感知/模型必须足够强——这就是无图方案为什么都配 BEV+Transformer 大感知模型（[[BEVFormer详解]]）的原因。

## 三、轻图：中间态

```
轻图 (Light Map / 轻地图):
  精度: 分米级 ~ 米级（介于 HD Map 和 SD Map 之间）
  内容: 关键要素（车道级拓扑，但不用厘米级几何）
  定位: "无图太激进，有图太贵"的折中
```

> 参考：从"有图"到"无图"再到"轻图"（[OFweek](https://www.ofweek.com/ai/2025-09/ART-201716-11000-30670466.html)）、[从高精地图到轻地图再到无图，谁才是真需求](https://iot.ofweek.com/2025-11/ART-132200-8110-30673360.html)

> [!note] 为什么会有"轻图"？
> 无图对感知压力太大（路口推理偶尔出错），有图太贵（覆盖不全）——**轻图 = 只留"关键拓扑先验"（路口怎么连），几何细节靠感知**。**"轻图"是 2025 年的务实趋势**：感知做细节、轻图做结构、导航做路线。

## 四、三方案对比表（必背）

| 维度 | 有图（HD Map） | 轻图 | 无图 |
|------|---------------|------|------|
| **地图精度** | 厘米级 | 分米~米级 | 仅导航地图（米级）|
| **地图内容** | 车道几何+属性+拓扑 | 关键拓扑 | 路线规划 |
| **细节来源** | 地图先验 | 地图+感知混合 | 实时感知+在线建图 |
| **覆盖** | 差（采集过才能开）| 中 | **好（全国可开）** |
| **时效** | 差（会过期）| 中 | **好（实时理解）** |
| **感知压力** | 小 | 中 | **大** |
| **成本** | 高 | 中 | **低（无地图维护）** |
| **代表** | 早期华为/百度 | 部分量产 | **华为/特斯拉/Momenta 主流** |

> [!warning] 记忆框架：三方案 = "先验程度"的谱系
> **有图（全先验）→ 轻图（半先验）→ 无图（零几何先验）**——沿着"感知能力增强、地图依赖减弱"的方向演进。**判断一个方案用哪种：看它"车道细节从哪来"（地图？感知？混合？）。**

## 七、关键洞察（面试深度题）

### 洞察 1："无图"≠"不用地图"

```
无图 = 不用高精地图，仍用导航地图 + 实时感知/在线建图
"无图"是营销词，技术本质是"地图先验 → 感知实时"的迁移
```

### 洞察 2：无图的能力要求 = 感知/模型的军备竞赛

```
有图: 地图兜底（车道细节地图给）→ 感知要求低
无图: 感知兜底（车道细节车自己看）→ 感知/模型要求高
→ 无图时代 = BEV/Transformer/端到端大模型的时代（[[BEVFormer详解]]/[[端到端自动驾驶概览]]）
```

### 洞察 3：记忆建图（Memory Mapping）——无图的进阶形态

```
记忆建图: 车反复走同一路段 → 把"感知结果"存成"记忆地图"
         → 第二次走不用重新推理（又快又稳）
代表: 华为/小鹏的"记忆行车"、特斯拉的在线语义地图
```

> [!note] 记忆建图的直觉
> 无图是"每次现看现想"，记忆建图是"看过一次就记住"——**同一路段走 3 次后，第 4 次就"有图"了（车自己攒的地图）**。这是"无图"和"有图"的融合形态：**"车自己画的地图"**。

### 洞察 4：轻图可能是终局（务实派）

```
无图感知压力大（路口偶尔错）→ 轻图只留"拓扑先验"（路口怎么连）
感知做细节 + 轻图做结构 + 导航做路线 = 2025 务实派方案
"无图是口号，轻图是现实，感知是基础"
```

## 八、常见误区速查

> [!warning] 新手最常踩的坑
> 1. **以为"无图"= 不用任何地图**——仍用导航地图 + 实时感知建图；"无图"指"无高精地图"。
> 2. **以为无图方案"更简单"**——恰恰相反：无图对感知/模型要求更高（车道细节全靠看）。
> 3. **混淆"无图"和"纯视觉"**——华为无图但用 LiDAR，特斯拉无图且纯视觉；"无图"是地图维度，"纯视觉"是传感器维度，两个不同概念。
> 4. **以为高精地图被"淘汰"了**——高精地图退到特定场景（Robotaxi 测试区、特殊道路），没有被消灭，是"退居二线"。
> 5. **忽视导航地图的角色**——无图方案仍然"依赖"导航地图（知道去哪），"无图"≠"无导航"。

## ✅ 检验自己（自测题）

> [!question] Q1：有图、无图、轻图的本质区别是什么？用一个维度概括。
> 提示：先验程度。

> [!success]- 参考答案
> 三者的本质区别是"车道细节从哪来"（地图先验程度）：有图 = 高精地图提供厘米级先验；轻图 = 只提供关键拓扑先验（细节靠感知）；无图 = 不用高精地图，车道细节全靠实时感知 + 在线建图（只用导航地图知道去哪）。谱系：全先验 → 半先验 → 零几何先验，对应感知能力递增、地图依赖递减。

> [!question] Q2："无图"的真相是什么？为什么说"无图≠不用地图"？
> 提示：导航地图 + 实时建图。

> [!success]- 参考答案
> "无图"指"不用高精地图"，但① 仍用普通导航地图（知道去哪）；② 路况细节靠实时感知 + 在线建图（RCR/语义建图）理解。所以"无图"是营销词，技术本质是"地图先验 → 感知实时"的迁移——车从"拿图纸开"变成"边开边画图"。"无图≠不用地图，≠无导航"。

> [!question] Q3：华为和特斯拉的无图方案有什么本质差异？
> 提示：传感器/实现方式。

> [!success]- 参考答案
> ① 传感器：华为多传感器（LiDAR 兜底 + 视觉），特斯拉纯视觉；② 实现：华为 RCR 显式在线建图（可审计），特斯拉端到端大模型"直接懂路"（黑盒）；③ 地图：华为用导航地图 + RCR，特斯拉完全不用高精地图（全球统一）；④ 哲学：华为赌"感知+工程"，特斯拉赌"数据+模型"。两家都"无图"，但"无图"的实现路线完全不同。

> [!question] Q4：Momenta 的"一个飞轮 + 两条腿"是什么？和地图方案什么关系？
> 提示：量产数据养 L4。

> [!success]- 参考答案
> "一个飞轮" = 量产数据 → 算法迭代 → 体验提升 → 更多数据的闭环（[[数据闭环总览]]）；"两条腿" = 腿 1 量产智驾（L2+，数据来源）+ 腿 2 Robotaxi（L4，技术天花板）。无图城市 NOA 是腿 1 的核心功能（感知+在线建图），量产车在无高精地图的城市也能开，同时为飞轮提供海量数据反哺 L4——"量产数据养 L4 技术"。

> [!question] Q5：为什么"无图"对感知能力要求更高？这解释了智驾技术演进的什么？
> 提示：感知兜底。

> [!success]- 参考答案
> 有图时车道细节由地图提供（感知压力小）；无图时车道细节全靠车自己看（感知压力大）——感知/模型成为"兜底"。这解释了智驾技术演进：无图时代 = BEV/Transformer/端到端大模型时代（[[BEVFormer详解]]/[[端到端自动驾驶概览]]），因为只有强感知+强模型才能"无图也能开"。**"无图"既是卖点，也是感知能力的试金石。**

## 🛠 动手练习

### 练习 1：画"有图/轻图/无图"三方案对比图（30 分钟）

用 Excalidraw 画三张"数据流图"（有图/轻图/无图），每张标注：
1. 地图输入（HD Map / 轻图 / 导航地图）
2. 感知输入（弱 / 中 / 强）
3. 车道细节从哪来（地图 / 混合 / 感知+在线建图）

> [!tip] 画完自问
> ① 三张图的核心差异在哪一步？（车道细节来源）② 把"记忆建图"加进去，无图是不是"越走越有图"？（是——反复走的路段会攒出车自己的地图）

### 练习 2：写"你们方案是无图吗"面试答法（45 分钟）

用"结论→展开→举例"写一段 250 字回答：
1. 结论：方案是无图/有图/轻图。
2. 展开：车道细节从哪来、用什么感知、依赖什么地图。
3. 举例：华为 RCR / 特斯拉 FSD / Momenta 城市 NOA 的真实案例。

> [!tip] 完成标准
> 能说清"无图≠不用地图""无图≠纯视觉"两个易混点；举出一个真实公司的具体实现。写完对照第六节的业界方案表。

### 练习 3：追踪"轻图"趋势（可选，长期）

在 [[华为智驾动态追踪]] 或本篇加一个"轻图观察"小节，每月记录：
1. 有没有车企从"无图"转向"轻图"？（2025-2026 趋势）
2. 记忆建图（车自己攒图）的落地案例。
3. 高精地图在 Robotaxi 的坚守情况。

> [!tip] 这是"有图/无图"话题的时效性追踪
> 地图方案 2-3 年就变一次（有图→无图→轻图），**追踪比背结论更重要**。配合 [[前沿追踪与面试准备]] 的月度机制。
