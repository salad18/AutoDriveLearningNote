# 数据闭环总览

> 数据闭环 = 智能驾驶系统的飞轮。数据从车上采集 → 云端训练 → 模型回车上 → 产生新数据 → 循环迭代。

---

## 一、为什么数据闭环至关重要

### 长尾效应

```
                    常见场景 (99.9%)
                    ╱
    ┌─────  数据量分布
    │
    ││││││││││││││││││││││││││││││││││││││││││││││││││││││││
    │                                            ╲
    │                                   corner case (0.1%)
```

- 99.9% 的驾驶数据是"正常行驶"（直行、跟车）
- 真正危险的 corner case 极其稀有
- 估计需要 **1000 亿公里** 驾驶数据才能覆盖长尾

**数据闭环的核心目标**：从海量平凡数据中，高效挖掘稀缺的 corner case，并用它来改进模型。

## 二、数据闭环 Pipeline

### 标准五步闭环

```
┌──────────────────────────────────────────────────────────┐
│                    数据闭环 (Data Loop)                    │
│                                                           │
│  ┌──────────┐     ┌──────────┐     ┌──────────┐          │
│  │ 1. 采集  │ →  │ 2. 挖掘  │ →  │ 3. 标注  │          │
│  │ Collect  │     │ Mine     │     │ Label    │          │
│  └──────────┘     └──────────┘     └──────────┘          │
│       ↑                                  ↓                │
│       │                           ┌──────────┐           │
│       │                           │ 4. 训练  │           │
│       │                           │ Train    │           │
│       │                           └────┬─────┘           │
│       │                                ↓                  │
│  ┌──────────┐                    ┌──────────┐            │
│  │ 6. OTA   │ ←──────────────── │ 5. 评测  │            │
│  │ Deploy   │                    │ Evaluate │            │
│  └──────────┘                    └──────────┘            │
└──────────────────────────────────────────────────────────┘
```

### 各环节详解

| 环节 | 做什么 | 关键挑战 |
|------|--------|----------|
| **1. 采集** | 量产车回传传感器数据 | PB 级数据量，带宽和存储成本 |
| **2. 挖掘** | 从海量数据中找到有价值的场景 | 如何定义"有价值" |
| **3. 标注** | 为原始数据添加真值标签 | 人工标注太慢太贵 |
| **4. 训练** | 用标注好的数据训练/微调模型 | 大模型训练算力需求巨大 |
| **5. 评测** | 开环+闭环评测模型效果 | 开环指标好 ≠ 闭环能跑 |
| **6. OTA** | 把新模型部署到量产车 | 安全验证，不能引入回归 |

## 三、业界数据闭环方案

### 特斯拉 Fleet Learning

```
量产车 Fleet → 影子模式 (Shadow Mode) → 触发采集 → 数据回传
                                                    ↓
                                          ┌─────────────────┐
                                          │ 自动标注 (Auto-label) │
                                          │ 数据引擎 (Data Engine) │
                                          │ 挖掘相似场景            │
                                          └────────┬────────┘
                                                   ↓
                                          Dojo 超算训练
                                                   ↓
                                          FSD Beta 推送
```

**核心机制**：
- **影子模式**：新模型在后台静默运行（不控车），对比人类驾驶行为，偏差大→回传该场景数据
- **触发器 (Trigger)**：特定事件触发数据采集（急刹、接管、AEB 激活等）
- **数据引擎**：发现一个 corner case → 自动检索相似场景 → 批量生成训练数据

### 华为 ADS 数据闭环

```
量产车 (百万级) ──→ 事件触发采集 ──→ 云端数据湖
                                        ↓
                              ┌──────────────────┐
                              │ 盘古大模型        │
                              │ ├── 自动标注      │
                              │ ├── 场景理解      │
                              │ ├── NeRF 3D 重建  │
                              │ └── 数据生成      │
                              └────────┬─────────┘
                                       ↓
                              昇腾集群训练 (7.5 EFLOPS)
                                       ↓
                              仿真验证 → OTA 推送 (5 天一迭代)
```

**关键数据**：
- 云训练算力：7.5 EFLOPS
- 每日训练数据：3500 万公里
- 模型迭代周期：**每 5 天**
- 累计智驾里程：7.36 亿公里 (截至 2024.10)
- 仿真日里程：超 10 亿公里 (2030 年预测)

### NVIDIA MagLev

```
Collect → Select → Label → Train → Test → Deploy
    ↑                                    │
    └────────────── 反馈 ────────────────┘
```

**两个闭环**：
1. **数据闭环**：数据摄入 → 智能筛选 → 标注 → 训练 → 测试
2. **基础设施闭环**：安全数据处理、可扩展 DNN、KPI 监控

## 四、数据闭环的核心技术

### 影子模式 (Shadow Mode)

```
车辆运行时:
  ├── 主模型 (Production):  实际控车
  └── 影子模型 (Shadow):     后台运行，输出与主模型对比

            如果影子模型输出 ≠ 人类驾驶行为 (超过阈值)
                ↓
            触发数据采集 → 回传该场景
```

### 事件触发器

| 触发类型 | 示例 | 价值 |
|----------|------|------|
| **安全事件** | AEB 激活, 急刹, 碰撞预警 | 极高 |
| **接管事件** | 人工接管、退出智驾 | 极高 |
| **模型不确定性** | 模型输出高熵(不确定) | 高 |
| **行为偏差** | 规划轨迹与实际轨迹偏差大 | 高 |
| **场景稀有性** | 特定天气、光照、道路类型 | 中 |

### 数据飞轮效应

```
更多车在路上 → 更多驾驶里程 → 更多 corner case → 更好模型
      ↑                                                    ↓
      └──────── 更好体验 → 更多人买 → 更多车 ───────────────┘
```

## 五、关键指标

| 指标 | 说明 |
|------|------|
| **数据回传率** | 回传数据量 / 总行驶里程 |
| **有效采集率** | corner case 占比 / 总回传数据 |
| **标注效率** | 标注 1 帧所需人时 (从小时→分钟→秒) |
| **训练周期** | 从采集到新模型上线的时间 |
| **闭环迭代速度** | 模型改进的"转速" |
| **OTA 覆盖率** | 成功更新车辆 / 总车辆 |

## 六、挑战与趋势

### 当前挑战

| 挑战 | 说明 |
|------|------|
| **长尾采集** | 最危险的场景最难采集 |
| **标注成本** | 3D 框+占据栅格标注极其昂贵 |
| **数据隐私** | 回传数据涉及隐私合规 |
| **仿真 gap** | 仿真数据训练出来的模型在真实世界可能退化 |
| **灾难性遗忘** | 新数据微调后，旧场景能力可能退化 |
| **回归风险** | 新模型在 corner case 上变好，但在常见场景变差 |

### 未来趋势

1. **大模型自动标注**：用 VLM/LLM 替代人工标注
2. **生成式数据增强**：NeRF/3DGS 重建→编辑→生成新 corner case
3. **持续学习**：不需要全量重训，持续增量学习
4. **云端协同训练**：车端轻量处理 + 云端重训
5. **闭环仿真验证**：先过仿真再上路，降低 OTA 风险
