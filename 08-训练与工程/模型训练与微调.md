# 模型训练与微调

> 大模型时代，自动驾驶模型的训练范式从"从头训练"转向"预训练+微调+持续学习"。

---

## 一、训练范式总览

```
┌─────────────────────────────────────────────────────┐
│                    训练金字塔                        │
│                                                     │
│                        ┌────────┐                   │
│                        │ 持续   │  OTA 后增量学习   │
│                        │ 学习   │                   │
│                    ┌───┴────────┴───┐               │
│                    │    微调        │  特定场景适配  │
│                    │  Fine-tuning   │               │
│            ┌──────┴────────────────┴──────┐        │
│            │        预训练                │  大规模通用 │
│            │       Pre-training           │  能力        │
│            └──────────────────────────────┘           │
└─────────────────────────────────────────────────────┘
```

## 二、预训练 (Pre-training)

### 自动驾驶中的预训练

| 预训练方式 | 数据 | 学什么 | 举例 |
|-----------|------|--------|------|
| **ImageNet 预训练** | 自然图像 | 通用视觉特征 | ResNet 初始化 |
| **自监督预训练** | 驾驶视频无标注 | 时序/3D 表征 | MAE, BEiT |
| **多模态预训练** | 图像+LiDAR+文本 | 跨模态对齐 | CLIP 风格 |
| **驾驶专项预训练** | 大规模驾驶数据 | BEV 特征、占据 | 华为 GOD 基础模型 |

### 为什么预训练重要

```
从头训练 (from scratch):
  需要: 海量标注数据 + 巨大算力 + 数周训练时间
  结果: 可能只学到当前数据集特征

预训练 + 微调:
  需要: 少量标注数据 + 适中算力 + 数小时微调
  结果: 继承通用知识 + 快速适配新场景
```

## 三、微调 (Fine-tuning)

### 微调策略分类

#### 按冻结程度

| 策略 | 做法 | 适用场景 |
|------|------|----------|
| **全量微调** (Full FT) | 所有参数可更新 | 大场景变化（如从美国适配中国） |
| **部分微调** (Partial FT) | 冻结 backbone，只训 head | 新增检测类别 |
| **LoRA** | 插入低秩适配矩阵 | 高效适配，参数少 |
| **Adapter** | 插入小型适配模块 | 多任务切换 |
| **Prompt Tuning** | 只学习少量 prompt token | VLM 适配驾驶场景 |

#### LoRA (Low-Rank Adaptation)

```
原始权重 W ∈ R^{d×d}  (冻结)
插入: A ∈ R^{d×r}, B ∈ R^{r×d}  (训练)
输出: h = W·x + B·A·x

参数量: 2×d×r  (r << d, 如 r=8)
```

**在自动驾驶中的应用**：
- 基础感知模型 → LoRA 微调 → 适配新车型/新传感器配置
- 每个城市的驾驶风格不同 → 不同 LoRA 权重

### 微调中的数据平衡

**核心问题**：微调数据通常偏向 corner case，容易导致**灾难性遗忘**。

```
错误做法: 只用 corner case 数据微调
  → 模型在 corner case 变好，但在常见场景退化

正确做法: 混合数据微调
  corner case 数据 (30%) + 原始数据回放 (70%)
  → 两个场景都好
```

## 四、持续学习 (Continual Learning)

### 为什么需要持续学习

自动驾驶的世界不断变化：
- 新的道路类型（如刚通车的隧道）
- 新的交通规则
- 新的障碍物类型
- 季节/天气变化

**不可能每次都全量重训**，需要增量更新。

### 持续学习三大方法

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **回放 (Replay)** | 保留核心数据集，和新数据混合训练 | 简单有效 | 需要存储旧数据 |
| **正则化 (Regularization)** | 惩罚重要参数的更新 (EWC, SI) | 不需要存储旧数据 | 效果有限 |
| **参数隔离 (Isolation)** | 不同任务用不同的参数子集 | 无遗忘 | 模型膨胀 |

### 业界实践：核心数据集回放 (Core Set Replay)

```
训练流程:
  1. 维护一个"核心数据集" D_core (如 10000 张代表性样本)
  2. 新 corner case 数据来了 → 和 D_core 混合训练
  3. 新模型经过测试 → 用不确定性采样更新 D_core
  4. 循环往复

优势:
  - D_core 只占原始数据 < 1%
  - 兼顾新旧场景
  - 训练效率高
```

### 华为 ADS 的训练节奏

```
数据采集 (车端) → 汇聚云端 → 自动标注
                              ↓
                     5 天一迭代:
                        ├── 增量数据 + 核心数据
                        ├── 昇腾集群训练
                        ├── 仿真评测
                        └── OTA 推送
```

## 五、多任务联合训练

### 自动驾驶常见多任务

```
共享 Backbone (BEV 特征)
    │
    ├── 3D 检测 Head
    ├── BEV 分割 Head
    ├── 车道线检测 Head
    ├── 占据预测 Head
    ├── 轨迹预测 Head
    └── 规划 Head
```

### 训练策略

| 策略 | 做法 | 适用 |
|------|------|------|
| **同步训练** | 所有任务一起训 | 任务相关性高 |
| **轮流训练** | 交替训不同任务 | 任务冲突时 |
| **课程学习** | 先简单后难 | 规控来架训需要先有感知能力 |
| **渐进式** | 逐步解冻层 | 预训练 backbone → 微调 head |

### UniAD 的两阶段训练

```
Stage 1: 感知模块预训练
  训练: BEV Encoder + TrackFormer + MapFormer + MotionFormer
  冻结: Planner

Stage 2: 端到端联合微调
  解冻所有模块
  联合优化: L_total = L_track + L_map + L_motion + L_occ + L_plan
```

## 六、损失函数设计

### 多任务损失平衡

```
总损失 = Σ w_i × L_i

如何确定 w_i？
```

| 方法 | 做法 | 特点 |
|------|------|------|
| **固定权重** | 手动设定 w_i | 简单但需要调参 |
| **不确定性加权** | w_i = 1/(2σ_i²), σ 可学习 | 自动平衡 |
| **梯度归一化** | GradNorm, 均衡各任务梯度大小 | 训练稳定性好 |
| **动态调整** | 根据各任务学习速度动态调整 | 复杂但效果好 |

### 自动驾驶特有损失

| 损失 | 用途 |
|------|------|
| **Focal Loss** | 目标检测分类（处理类别不平衡） |
| **L1/Smooth L1** | 3D 框回归 |
| **IOU Loss** | 检测框质量 |
| **深度监督 Loss** | BEVDepth 用 LiDAR 点云监督深度 |
| **Collision Loss** | 规划轨迹碰撞惩罚 |
| **Imitation Loss** | 模仿人类驾驶行为 |
| **Contrastive Loss** | 学习区分性特征（Re-ID） |

## 八、关键概念速记

| 概念 | 含义 |
|------|------|
| **Pre-training** | 在大规模通用数据上训练基础能力 |
| **Fine-tuning** | 在特定数据上调整模型适应新任务 |
| **LoRA** | 低秩适配，参数高效的微调方法 |
| **Catastrophic Forgetting** | 灾难性遗忘：学新→忘旧 |
| **Replay Buffer** | 回放缓存，保存旧数据防止遗忘 |
| **Multi-task Learning** | 多任务联合学习，共享表征 |
| **Curriculum Learning** | 课程学习，从简单到困难 |
| **Knowledge Distillation** | 知识蒸馏，大模型教小模型 |
