# 多传感器融合与故障降级

> 面试官必问：「如果 LiDAR 突然挂了，你的系统怎么降级？」

---

## 一、时间同步 — 传感器对齐的根基

### 1.1 各传感器的时间特性

| 传感器 | 频率 | 延迟 | 数据类型 |
|--------|:---:|:---:|------|
| Camera | 30 Hz | ~33ms | 曝光中心时刻 |
| LiDAR | 10 Hz | ~100ms | 扫描起始时刻 |
| Radar | 20 Hz | ~50ms | 单次测量 |
| IMU | 200 Hz | ~5ms | 连续 |
| GNSS | 10 Hz | ~100ms | 单次定位 |

**核心挑战**: 不同频率、不同延迟 → 必须对齐到同一时刻。

### 1.2 时间同步方案

```
方案 A: 硬件同步 (PTP/gPTP, 精度 <1ms)
  ┌─────────┐
  │GPS/GNSS │ → PPS (Pulse Per Second) → 所有传感器
  └─────────┘   每个传感器收到 PPS 时打时间戳 → 硬件级对齐
  成本: 需要支持 PTP 的传感器 (高端 LiDAR 标配)

方案 B: 软件同步 (ROS message filter, 精度 ~10ms)
  camera_msg (t=1000) ─┐
  lidar_msg  (t=1003) ─┤ → ApproximateTimeSynchronizer
  radar_msg  (t=1005) ─┘    → 容忍 10ms 窗口 → 匹配为一组
  成本: 零 (纯软件)

方案 C: 插值对齐 (精度 <5ms)
  t=1000: camera frame
  t=1010: LiDAR frame
  → 线性插值 LiDAR 点云到 t=1000 (利用 IMU 补偿运动)
  → 将 10ms 的 LiDAR 扫描运动补偿到 camera 曝光时刻
```

### 1.3 时间不对齐的后果

```python
# 车速 60 km/h = 16.7 m/s
# 时间误差 50ms → 位置误差 = 16.7 × 0.05 = 0.83m

# 对 BEV 投影的影响:
# camera t=1000, lidar t=1050 (50ms 延迟)
# 自车在 50ms 内前进了 0.83m
# → 用 camera 时刻的外参投影 lidar 点 → 所有点偏移 0.83m
# → 前方 30m 的车辆 BEV 位置偏差 0.83m → IoU 下降 15%

# 解决方案: 用 IMU 积分补偿 50ms 内的自车运动
ego_motion_50ms = integrate_imu(imu_data, t=1000, t=1050)
compensated_lidar = apply_transform(lidar_points, ego_motion_50ms)
```

## 二、外参标定 — 坐标系对齐

### 2.1 标定漂移的影响

| 外参误差 | 30m 处投影误差 | NDS 影响 |
|:------:|:----------:|:-----:|
| **平移** 0.05m | 0.05m (与深度无关) | -0.3 |
| 平移 0.10m | 0.10m | -1.2 |
| **旋转** 0.1° | 0.052m | -0.5 |
| **旋转** 0.5° | 0.26m | -3.0 ⚠️ |
| 旋转 1.0° | 0.52m | -6.0 🔴 |

**结论**: 旋转误差比平移误差破坏性大得多 — 远处物体被放大。

### 2.2 在线标定检测

```python
# 如何发现标定漂移:
# 方法 1: LiDAR-Camera 投影一致性检查
lidar_pts_projected = project_lidar_to_camera(lidar_points, K, RT)
# 在图像上检查: LiDAR 投影点应该落在物体的像素上
# 如果有系统性偏移 → 标定漂移
# 指标: 投影点到最近 edge pixel 的平均距离

# 方法 2: 多帧一致性检查
# 用 SfM 从图像序列估计相机运动
# 用 LiDAR odometry 估计自车运动
# 两个运动应该一致 → 如果不一致 → 相机-LiDAR 外参有问题

# 方法 3: 路面平面检查
# LiDAR 检测的路面平面和相机推断的路面平面应该重合
```

## 三、传感器故障与降级策略

### 3.1 故障类型

| 故障 | 表现 | 检测方法 |
|------|------|----------|
| **Camera 遮挡** | 全黑/全白/部分遮挡 | 像素方差 < 阈值 |
| **Camera 脏污** | 局部模糊/对比度下降 | 高频分量减少 |
| **LiDAR 失效** | 无点云输出 | 点云数量 < 阈值 |
| **LiDAR 衰减** | 点云变稀疏 (老化) | 点云密度对比历史 |
| **Radar 噪声** | 大量 ghost detection | 检测数量异常 |
| **时间戳跳变** | 传感器时间不同步 | 时间戳差值监控 |

### 3.2 降级策略矩阵

```
                     LiDAR
                 正常      异常
          ┌───────────┬───────────┐
    正常  │ Full Fusion│ Camera-   │
          │ (最佳)     │ Only      │
Camera    │            │ (NDS -15) │
          ├───────────┼───────────┤
    异常  │ LiDAR-Only │ Emergency │
          │ (NDS -10)  │ Stop      │
          └───────────┴───────────┘
```

### 3.3 纯视觉 Fallback 的实际表现

```python
# Camera-Only (6 cameras, no LiDAR) vs Full Fusion (Camera + LiDAR):
# nuScenes val set:
# Full Fusion: NDS=65.0, mAP=60.0
# Camera-Only:  NDS=48.0, mAP=42.0
# Δ: NDS -17, mAP -18

# 什么场景退化最大:
# 1. 夜间/雨雾 (相机退化 + 无 LiDAR) → -25 NDS
# 2. 远距离 (>80m, LiDAR 的主要优势范围) → -20 NDS
# 3. 密集交通 (LiDAR 提供精确 3D 位置) → -15 NDS
# 4. 高速公路 (相对简单) → -8 NDS

# 降级策略:
# 如果 Camera-Only NDS < 安全阈值 → 限速 (如 60km/h → 40km/h)
# → 将 ODD (Operational Design Domain) 缩小到模型可靠的范围
```

### 3.4 LiDAR 衰减检测 — 渐进式故障

```python
# LiDAR 不是突然挂，是逐渐衰减 (发射器老化)
# 检测方法:
def detect_lidar_degradation(current_scan, historical_baseline):
    # 1. 点云密度对比
    density = len(current_scan.points) / current_scan.fov_area
    baseline_density = historical_baseline['avg_density']
    
    # 2. 反射强度对比
    intensity = current_scan.points.intensity.mean()
    baseline_intensity = historical_baseline['avg_intensity']
    
    # 3. 有效距离对比
    max_range = current_scan.points.distance.max()
    
    if density < 0.7 * baseline_density:  # 衰减 30%
        alert("LiDAR degradation detected, schedule maintenance")
    if density < 0.5 * baseline_density:
        switch_to_camera_only_mode()
```

## 四、面试官追问

### Q: 你的融合方案中，Camera 和 LiDAR 检测结果冲突时（如 Camera 检测到一个行人，LiDAR 没看到），你信谁？

这是融合策略的核心问题 — **不存在永远正确的单一传感器**。

决策矩阵:
```
场景分析:
1. 如果是白天 + 近距 (<30m):
   信 Camera (行人检测 Camera >> LiDAR，LiDAR 可能因遮挡没扫到)
   
2. 如果是夜间:
   信 LiDAR (Camera 低光照检测不可靠)
   
3. 如果是远距 (>80m):
   信 LiDAR (Camera 深度模糊)
   
4. 如果是异形障碍物:
   信 Camera (语义理解强) + LiDAR (几何验证)
   → 两者都不可靠时 → 标记为 "unknown obstacle" → 保守处理

5. 如果冲突持续 N 帧 (>3帧):
   取并集 (两个都要躲) — 安全优先
```

### Q: 多传感器融合时，不同传感器的检测结果怎么关联 (association)？

```python
# 核心: 3D 空间的 IoU/距离匹配
def associate_detections(cam_dets, lidar_dets, radar_dets):
    # 1. 将所有检测投影到 BEV 空间
    all_bev_boxes = []  # list of (bbox, source, confidence)
    
    # 2. 匈牙利匹配 (或贪心匹配)
    # cost = 1 - BEV_IoU(box_a, box_b)
    matches = hungarian_matching(cam_boxes, lidar_boxes, cost_matrix)
    
    # 3. 对匹配上的 pair → 融合 (加权平均 BBox + max confidence)
    for (cam_id, lidar_id) in matches:
        fused_box = (cam_conf * cam_box + lidar_conf * lidar_box) / (cam_conf + lidar_conf)
    
    # 4. 未匹配的单模态检测 → 保留 (可能另一模态漏检了)
    unmatched = cam_unmatched + lidar_unmatched
    
    return fused + unmatched
```
