## 一、长期扩展路线图（8 大方向）

> 每个方向 = 用户需求 + 与智驾的共通点。**扩展时的核心问题：这个前沿方向能反哺我对智驾的理解吗？共通点在哪？**

### 1. VLA（Vision-Language-Action）🔥 已完成首篇

| 项目 | 内容 |
|------|------|
| **是什么** | 视觉-语言-动作模型：感知（视觉）+ 推理（语言）+ 控制（动作）三合一，是端到端自动驾驶与具身智能的**共同底座** |
| **代表作** | π0（VLA Flow Model，通用机器人）、DriveVLA-W0（世界模型放大数据规模）、Orion（视觉语言指令生成动作）、Alpamayo-R1（NVIDIA，推理+动作预测） |
| **与智驾共通点** | ① 都是"多模态输入 → 动作输出"；② 都用 [[三阶段训练范式]]（Pretrain→SFT→RL）；③ 都面临分布漂移/幻觉 |
| **进度** | ✅ [[VLA入门与智驾应用]] 已扩充（2026-08-21）；后续按月度更新补充新论文解读 |

### 2. 具身智能（Embodied AI）🔥 优先

| 项目 | 内容 |
|------|------|
| **热点是什么** | 大模型（VLM/LLM）赋予机器人"理解+规划+操作"能力；2025 年国内爆发（北京人形 XR-1 开源 VLA 通过国标测试） |
| **关键概念** | 具身智能 = AI + 机器人本体；VLA 是大脑；世界模型是想象力 |
| **与智驾共通点** | ① 智驾是"轮式具身智能"（车就是机器人本体）；② 同为"感知→决策→控制"闭环；③ 世界模型/端到端方法高度共享 |
| **计划** | 新笔记 `具身智能热点追踪`：人形机器人 vs 智驾的架构对比 → XR-1/π0 等案例 → 技术迁移点 |

## 二、月度更新机制（保持时效性）

> **核心：每月一次，用 DSH 更新知识库**。每次更新 = 一次"时效性体检"。

### 月度更新清单（每次按此执行）

```markdown
□ 1. 前沿扫描（30 分钟）
   - web_search 检索：VLA / 具身智能 / 端到端智驾 / 大模型训练 / AI Infra / 华为智驾 / 面经
   - 记录 3-5 个"本月值得追踪"的热点到本篇第六节
□ 2. 论文追踪（1-2 小时）
   - arXiv 检索 cs.CV / cs.RO / cs.LG 关键词（BEV / occupancy / end-to-end / VLA / world model）
   - 选出 1-2 篇"必读"，用 [[论文笔记模板]] 写解读
   - 下载 PDF 存到 Attachments/（或记录 arXiv 链接）
□ 3. 面经补充（30-60 分钟）
   - 检索牛客/CSDN/掘金新面经 → 补充到 [[智驾算法面试题库]]
   - 更新 [[常见面试题-感知算法]] 的热点题
□ 4. 华为/量产动态（30 分钟）
   - 检索华为乾崑/特斯拉 FSD/理想/小鹏动态 → 更新 [[华为智驾动态追踪]]
□ 5. 收尾（15 分钟）
   - 更新本篇"截至日期" → 更新 [[000-知识库地图]] 状态
   - git commit（`docs: 月度更新 YYYY-MM`）+ push
```

### 时效性原则

1. **每篇前沿笔记标注"截至 YYYY-MM"**——过期内容一目了然。
2. **热点素材只记"事实+链接"，不记"观点"**——观点容易过期，事实和出处可追溯。
3. **优先官方/论文来源**（arXiv/机构官网），二手博客仅作线索。
4. **"1-2 篇精读 > 10 篇泛读"**——每月精读的论文用 [[论文笔记模板]] 写透。

## 三、论文追踪与解读机制

### 论文怎么找（每月）

| 渠道 | 用法 |
|------|------|
| **arXiv** | 订阅 cs.CV / cs.RO / cs.LG；按关键词搜（BEV/occupancy/end-to-end/VLA/world-model/e2e-driving） |
| **Awesome 清单** | [Awesome-LLM4AD](https://raw.githubusercontent.com/Thinklab-SJTU/Awesome-LLM4AD/main/README.md)（LLM 用于自动驾驶的持续清单） |
| **综述论文** | World Models 全面综述（ACM Computing Surveys 2025）等——综述是"热点地图" |
| **顶会** | CVPR / ICCV / ECCV / NeurIPS / CoRL / ICRA——6 月/10 月等是论文季 |

### 论文解读模板（用 [[论文笔记模板]]）

```
1. 一句话贡献（这篇解决了什么）
2. 和本库哪篇笔记对照（如 "DriveVLA-W0 对照 [[世界模型]]"）
3. 3 个必背要点（面试可用）
4. 1 个可质疑点（批判性阅读）
5. 我的收获（写进 [[2026-08-20]] 或月报）
```

### 论文文件管理

```
Attachments/papers/YYYY-MM/
├── <short-name>_<arxiv-id>.pdf    ← 下载的 PDF（或只记链接）
└── 解读笔记 → 04-论文阅读/ 按方向归档
```

## 四、面试准备机制

### 面经搜集渠道

| 渠道 | 说明 |
|------|------|
| **牛客网** | 校招面经主力（虹软/ Momenta / 华为智驾等） |
| **CSDN** | 深度面经整理（Momenta 10 道高频题+答案解析 等） |
| **掘金/知乎** | 算法工程师面经、行业趋势 |
| **一亩三分地** | 国外自动驾驶公司面经 |

### 面试题整理规则

1. **按主题分组**：感知（BEV/3D 检测）/ 端到端 / 训练 / 部署 / Coding / 八股。
2. **每题三件套**：问题 + 答题框架（先结论→展开→举例）+ 关联笔记链接。
3. **高频标记**：被多家公司问的题标 🔥（如"BEVFormer 原理"）。
4. **每月补充**：新面经 → 更新 [[智驾算法面试题库]]。
