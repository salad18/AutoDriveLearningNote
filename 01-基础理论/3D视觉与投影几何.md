# 3D 视觉与投影几何

> 从 2D 图像到 3D 世界的核心数学 —— 相机模型、坐标变换、投影。

---

## 一、相机模型

### 针孔相机模型

```
世界点 P_w(X, Y, Z) → 相机坐标系 → 图像平面 (u, v)

投影方程：
s · [u, v, 1]^T = K · [R|t] · [X, Y, Z, 1]^T

其中：
  K = 内参矩阵 (3×3)
  R = 旋转矩阵 (3×3)
  t = 平移向量 (3×1)
  s = 深度 (标量)
```

### 内参矩阵 K

```
K = [f_x,  0,  c_x]
    [ 0,  f_y, c_y]
    [ 0,   0,   1 ]

f_x, f_y: 焦距 (像素)
c_x, c_y: 主点偏移 (像素)
```

### 外参 [R|t]

- **R**：3×3 旋转矩阵，描述相机朝向
- **t**：3×1 平移向量，描述相机位置
- **ego pose**：自车在世界坐标系的位姿，也由 R 和 t 表示

### 畸变模型

| 畸变类型 | 原因 | 影响 |
|----------|------|------|
| **径向畸变** | 镜头弯曲 | 桶形/枕形失真 |
| **切向畸变** | 镜头与传感器不平行 | 偏移失真 |

## 二、坐标系变换

### 自动驾驶中涉及的坐标系

```
世界坐标系 (World)
    ↓ [ego pose]
自车坐标系 (Ego / Vehicle)
    ↓ [camera extrinsics]  
相机坐标系 (Camera)
    ↓ [camera intrinsics / projection]
图像坐标系 (Image / Pixel)
```

### BEV 中的坐标变换链

```
BEV Grid (x, y) → 3D 世界点 (x, y, z_pred) → 相机坐标 → 像素坐标 (u, v)
                                                                   ↓
                                                            在 2D 特征图上采样
                                                                   ↓
                                                            得到该 BEV 格的视觉特征
```

## 三、投影方式分类

### 显式投影（LSS 方式）

```
2D 图像特征 + 深度估计 → 3D 体素 (Frustum Voxels) → 拍平 → BEV 特征
```

**代表方法**：LSS, BEVDet, BEVDepth, BEVDet4D

**优点**：显式，可解释
**缺点**：深度估计不准影响全局

### 隐式投影（Transformer 方式）

```
BEV Queries → Cross-Attention → 直接查询图像特征 → BEV 特征
```

**代表方法**：BEVFormer, PETR

**优点**：端到端学习，避免深度不准
**缺点**：计算量大，不易解释

### 前向投影 vs 后向投影

| 方向 | 描述 | 方法 |
|------|------|------|
| **2D → 3D** (前向) | 图像像素投影到 3D 空间 | LSS, BEVDet |
| **3D → 2D** (后向) | 3D 采样点投影到图像查询 | BEVFormer, PETR |

## 四、深度估计

### 为什么深度估计难

单目图像中，每个像素对应一条射线上的无穷多个 3D 点，缺乏深度信息。

### 解决方案

| 方法 | 思路 | 代表 |
|------|------|------|
| **深度分布预测** | 预测每个像素的离散深度概率分布 | LSS, BEVDet |
| **深度监督** | 用 LiDAR 点云监督深度预测 | BEVDepth |
| **双目/时序** | 多视角几何重建深度 | BEVStereo |
| **隐式学习** | Transformer 隐式编码深度信息 | BEVFormer, PETR |

## 五、3D 数据表示

### 点云 (Point Cloud)

- LiDAR 直接采集
- 稀疏、无序、包含精确 3D 坐标和反射强度
- 降采样方法：FPS (最远点采样)

### 体素 (Voxel)

- 将 3D 空间划分为均匀网格
- 优点：规则结构，可用 3D CNN
- 缺点：分辨率 vs 显存的权衡

### 柱体 (Pillar)

- 只在 XY 平面划分，Z 维度不切分
- 平衡了稀疏性和结构性
- **PointPillars** 是经典方法

### BEV 栅格

- 3D 体素在 Z 方向的压缩
- 最常用的自动驾驶感知表示

### 三视角平面 (Tri-Perspective View / TPV)

- 三个正交平面：XY (俯视), XZ (前视), YZ (侧视)
- 降低 3D 表示的显存开销
- **TPVFormer** 的核心思想

## 六、关键概念速记

| 概念 | 含义 |
|------|------|
| **FOV** | 视场角，如 120° 广角 |
| **Voxel** | 3D 体素，如 0.2m×0.2m×0.2m |
| **Ego-motion** | 自车运动，用于时序对齐 |
| **Homogeneous Coordinates** | 齐次坐标，(X,Y,Z,1) 形式 |
| **Depth from Stereo** | 双目视差 → 深度 |
| **LSS** | Lift-Splat-Shoot，BEV 视图变换基础范式 |
