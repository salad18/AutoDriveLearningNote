# 计算机视觉基础

> 自动驾驶感知的基础 —— 从 2D 图像理解到 3D 目标检测。

---

## 一、卷积神经网络（CNN）

### 核心组件

| 组件 | 作用 | 关键理解 |
|------|------|----------|
| **卷积层** | 提取局部特征 | 共享权重，平移不变性 |
| **池化层** | 降采样、增大感受野 | MaxPool / AvgPool |
| **激活函数** | 非线性变换 | ReLU / GELU / SiLU |
| **批归一化** | 加速训练、防止过拟合 | BatchNorm / LayerNorm |
| **全连接层** | 特征到输出映射 | 通常只在分类头使用 |

### 常见 Backbone

| 网络 | 年份 | 核心创新 | 在 BEV 中的使用 |
|------|------|----------|------------------|
| **ResNet** | 2015 | 残差连接，解决梯度消失 | 最广泛使用的 Backbone |
| **ResNet-50/101** | - | 标准配置 | BEVFormer, BEVDet |
| **VoVNet** | 2019 | OSA 模块，高效推理 | FCOS3D |
| **Swin Transformer** | 2021 | 层次化 Transformer | BEVFormer v2 |
| **InternImage** | 2023 | 可变形卷积 v3 | FB-BEV |

### FPN（特征金字塔网络）

```
输入图像 → Backbone → C2/C3/C4/C5 (多尺度特征)
                         ↓
                      FPN → P2/P3/P4/P5 (融合后的多尺度特征)
                         ↓
                      Neck (如 BiFPN)
```

**重要性**：BEV 感知需要同时检测近处小车和远处大车，FPN 提供多尺度特征支持。

## 二、目标检测

### 2D 检测经典方法

| 方法 | 类型 | 核心思想 |
|------|------|----------|
| **Faster R-CNN** | Two-stage | RPN 生成候选框 → 分类+回归 |
| **YOLO 系列** | One-stage | 直接回归边界框，速度快 |
| **FCOS** | Anchor-free | 基于中心点预测，去掉 anchor |
| **DETR** | Transformer | 端到端二分图匹配 |

### 3D 检测（通往 BEV 的必经之路）

3D 目标检测需输出：`(x, y, z, w, h, l, θ)` — 3D 位置 + 尺寸 + 朝向。

| 方法 | 输入 | 核心方法 |
|------|------|----------|
| **FCOS3D** | 单目图像 | 2D 检测 + 深度回归 |
| **PGD** | 单目图像 | 几何关系图 + 深度传播 |
| **PETR** | 多视图 | 3D 位置编码 + DETR |
| **DETR3D** | 多视图 | 3D object query 投影到 2D 采样 |

## 三、语义分割 & 实例分割

| 任务 | 粒度 | 输出 | 在自动驾驶中 |
|------|------|------|-------------|
| **语义分割** | 像素级 | 每个像素的类别 | 可行驶区域、车道线 |
| **实例分割** | 目标级 | 每个实例的 mask | 区分不同的车/人 |
| **全景分割** | 统一 | 语义 + 实例 | 完整的场景理解 |

### 关键模型

- **FCN / U-Net**：Encoder-Decoder 结构
- **DeepLab 系列**：空洞卷积 + ASPP
- **Mask R-CNN**：检测 + 分割
- **MaskFormer / Mask2Former**：统一分割范式

---

## 四、目标跟踪

| 范式 | 方法 | 自动驾驶中的应用 |
|------|------|-----------------|
| **TBD** (Tracking-by-Detection) | 检测 → 关联 | 主流方案 |
| **JDT** (Joint Detection & Tracking) | 统一框架 | CenterTrack 等 |
| **MOTR** | Transformer 跟踪 | 端到端时序 |

### 关键组件

- **卡尔曼滤波**：运动状态预测
- **匈牙利算法**：检测框匹配
- **Re-ID 特征**：外观匹配
- **3D Kalman Filter**：BEV 空间中的跟踪更稳定

---

## 五、关键概念速记

- **感受野**：输出特征图上每个像素对应的输入区域大小
- **IOU**：交并比，衡量检测框重叠度，`IOU = 交集 / 并集`
- **NMS**：非极大值抑制，去除重复检测框
- **mAP**：mean Average Precision，检测通用指标
- **mIoU**：mean Intersection over Union，分割通用指标
- **NDS**：nuScenes Detection Score，综合检测指标
