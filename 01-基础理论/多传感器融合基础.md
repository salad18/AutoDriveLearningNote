# 多传感器融合基础

> 自动驾驶需要多种传感器协同工作。融合是核心难题 —— 不同模态、不同频率、不同视角。

---

## 一、传感器对比

| 传感器 | 数据形式 | 优点 | 缺点 | 成本 |
|--------|----------|------|------|:--:|
| **相机 (Camera)** | 2D 图像/视频 | 语义丰富、纹理细节 | 无深度信息、受光照天气影响 | 低 |
| **激光雷达 (LiDAR)** | 3D 点云 | 精确 3D 位置、全天候 | 稀疏、无纹理、远距离稀疏 | 高 |
| **毫米波雷达 (Radar)** | 点/簇 + 速度 | 测速精准、恶劣天气可靠 | 分辨率低、杂波多 | 低 |
| **超声波雷达** | 距离 | 近距离精确、极低成本 | 范围短、信息少 | 极低 |
| **高精地图 (HD Map)** | 结构化矢量 | 先验信息、超视距 | 维护成本高、不实时 | 中 |
| **IMU/GPS** | 位姿/速度 | 定位基础 | 城市峡谷/隧道不可靠 | 低 |

## 二、融合策略

### 按融合位置分类

```
早期融合 (Early Fusion)
├── 原始数据/低级特征融合
├── 优点：信息损失少
└── 缺点：对齐困难，模态差异大

中期融合 (Middle Fusion)
├── 在特征空间融合（BEV 空间）
├── 优点：平衡了信息量和对齐难度
└── 代表：BEVFusion, TransFusion, DeepInteraction

晚期融合 (Late Fusion)
├── 各自独立检测→结果融合
├── 优点：简单，模块独立
└── 缺点：丢失互补信息
```

### 融合方式对比

| 融合方式 | 数据流 | 代表方法 | 优缺点 |
|----------|--------|----------|--------|
| **Proposal-level** | 各模态生成 proposal → 融合 | MVX-Net | 简单但割裂 |
| **Point-level** | 点云增强：图像特征附加到 LiDAR 点 | PointPainting | 依赖 LiDAR 质量 |
| **BEV-level** | 统一转换到 BEV 空间融合 | BEVFusion | 统一表示，主流方向 |
| **Query-level** | Transformer Query 交叉查询 | TransFusion | 灵活，端到端 |
| **Voxel-level** | 3D 体素内融合 | OccFusion | 细粒度，计算量大 |

## 三、主流融合框架

### BEVFusion (2023, MIT)

```
Camera Stream:     图像 → Backbone → FPN → View Transform → Camera BEV
LiDAR Stream:      点云 → Voxelization → 3D Encoder → Compression → LiDAR BEV
                                                                    ↓
                              Concat + BEV Encoder → Unified BEV Features
                                                                    ↓
                                                             Detection Head
```

**核心贡献**：
- 在 BEV 空间中统一融合 Camera 和 LiDAR 特征
- 预处理加速：GPU 加速体素化
- 多任务头：3D 检测 + BEV 分割

### TransFusion (2022)

```
LiDAR 点云 → Pillar Encoder → LiDAR BEV
                                 ↓
                        Transformer Decoder
                           LR → HR queries
                                 ↓
                     Cross-Attention with Image Features
                                 ↓
                         3D Bounding Boxes
```

**核心创新**：
- LiDAR-first 设计：以 LiDAR 检测为基础，图像作为增强
- Soft Association：不强制硬关联，让模型自主学习跨模态对应

### DeepInteraction (2023)

- 双向交互融合：图像特征增强点云，点云特征引导图像
- 多轮 Encoder-Decoder 交互

## 四、融合中的核心挑战

### 1. 时空对齐

| 挑战 | 说明 | 解决方案 |
|------|------|----------|
| **时间同步** | 不同传感器采集频率不同（Camera 30Hz, LiDAR 10Hz） | 插值/外推到同一时间戳 |
| **空间标定** | 各传感器外参不同，需要精确标定到同一坐标系 | 标定板 + 在线标定 |
| **运动补偿** | 传感器采集期间车在运动 | IMU 补偿、运动畸变校正 |

### 2. 模态差异

- **密度差异**：图像密集 (H×W)，点云稀疏
- **语义差异**：图像有纹理/颜色，点云只有几何
- **视角差异**：图像是透视，点云是 3D

### 3. 计算效率

- 多模态意味着多路 Backbone
- BEV 投影是计算瓶颈
- 需要设计轻量融合模块
