## 一、常用损失函数

### 分类损失

```
CrossEntropy (交叉熵):
  L_CE = -Σ y_c · log(p_c)  → 最基础的分类损失
  问题: 对类别不平衡敏感

Focal Loss (焦点损失):
  FL(p_t) = -(1-p_t)^γ · log(p_t)
  - γ=0 → 标准 CE
  - γ=2 → 常用值, 大幅降低简单样本权重
  - α: 类别加权 (如 α=0.75 for rare class)
  
  适用: 3D 检测中的正负样本不平衡 (BEV grid 中大部分是背景)

Quality Focal Loss (QFL):
  将 IoU 分数作为分类标签的 soft target
  L_QFL = -|y - σ|^β · ((1-y)·log(1-σ) + y·log(σ))
  适用: 需要同时预测类别和质量的场景
```

### 回归损失

```python
# L1 Loss: |x - y| → 对离群点不敏感, 零点不可导
# Smooth L1: 0.5x² if |x|<1 else |x|-0.5 → 兼顾两者

# GIoU Loss (Generalized IoU):
# L_GIoU = 1 - IoU + |C \ (A∪B)| / |C|
# 其中 C 是 A 和 B 的最小外包矩形 → 解决 IoU=0 时梯度消失

# DIoU Loss (Distance IoU):
# L_DIoU = 1 - IoU + ρ²(b_A, b_B) / c²
# ρ = 中心点距离, c = 最小外包矩形对角线距离
# → 中心点直接回归, 收敛更快

# CIoU Loss (Complete IoU):
# L_CIoU = 1 - IoU + ρ²/c² + α·v
# v = 4/π² · (arctan(w/h) - arctan(w_gt/h_gt))²  ← 长宽比一致
# α = v / (1 - IoU + v)  ← 动态权重
```

### 分割损失

```python
# Dice Loss: 直接优化 IoU
Dice = 2|X∩Y| / (|X|+|Y|)
L_Dice = 1 - Dice

# BCE + Dice (最常用组合):
L = L_BCE + λ·L_Dice  # λ 通常 0.5-1.0

# Lovász-Softmax: 直接优化 mIoU 的 surrogate
# 对类别不平衡更鲁棒
```

### BEV 感知特有损失

```python
# Depth Supervision Loss (BEVDepth):
# 用 LiDAR 点云投影到图像 → 得到稀疏深度真值
# → 监督 depth distribution 网络
L_depth = BinaryCrossEntropy(depth_pred, depth_gt_from_lidar)

# Ego-motion Loss:
# 自车运动预测 vs 实际 IMU/里程计
L_ego = SmoothL1(ego_pred, ego_gt)

# Planning Loss (UniAD):
# 碰撞惩罚 + 偏离目标惩罚 + 舒适度惩罚
L_plan = λ1·L_collision + λ2·L_deviation + λ3·L_comfort
```

## 二、训练超参数调优

### 学习率策略

| 策略 | 公式 | 优点 | 适用 |
|------|------|------|------|
| **Step Decay** | lr = base × γ^(step/stepsize) | 简单 | Baseline |
| **Cosine Annealing** | lr = lr_min + 0.5(lr_max-lr_min)(1+cos(π·T/T_max)) | 平滑 | 主流选择 |
| **Linear Warmup + Cosine** | warmup: lr linear↑, then cosine↓ | 稳定 | 大模型 |
| **OneCycleLR** | 先升后降 + 最终退火 | 快速收敛 | 微调 |
| **CyclicLR** | 周期性升降 | 逃离局部最优 | 训练震荡时 |

```python
# 推荐配置
optimizer = AdamW(params, lr=2e-4, weight_decay=0.01)  # BEV 模型
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer, T_max=total_steps - warmup_steps, eta_min=1e-6
)
# warmup 在 trainer 中手动实现
```

### 优化器选择

| 优化器 | 适用场景 | 推荐 LR | 注意事项 |
|--------|----------|---------|----------|
| **AdamW** | Transformer, 端到端 | 1e-4 ~ 2e-4 | weight_decay=0.01~0.1 |
| **SGD + Momentum** | CNN (ResNet, CenterPoint) | 0.01 ~ 0.1 | momentum=0.9, 需要 LR warmup |
| **LAMB** | 超大 batch (8K+) | 1e-3 ~ 5e-3 | 自适应 LR per layer |
| **Adam** | 不建议 (无 decoupled weight decay) | — | 用 AdamW 代替 |

**关键区别**：
- AdamW: weight decay 直接作用于参数，不与梯度耦合 → 更好的泛化
- SGD: 需要更仔细的 LR tuning，但有时最终精度更高

### Batch Size 影响

```
Linear Scaling Rule (Goyal et al., 2017):
  batch_size × N → lr × N (近似线性缩放)

  例: bs=32, lr=0.1 → bs=256, lr=0.8 (但实际需要微调)

实际经验:
  - 小 bs (2-8): 每步噪声大 → 需要大 LR 和 more epochs
  - 中 bs (16-64): 标准配置
  - 大 bs (256+): 需要 LARS/LAMB 优化器
  - BEV 模型: bs=4-16 per GPU 常见 (显存限制)
```

### EMA (Exponential Moving Average)

```python
# 维护一个参数的滑动平均版本，推理时使用 EMA 模型
class EMA:
    def __init__(self, model, decay=0.9999):
        self.model = model
        self.decay = decay
        self.shadow = {name: param.clone().detach() 
                       for name, param in model.named_parameters()}
    
    def update(self):
        for name, param in self.model.named_parameters():
            self.shadow[name] = self.decay * self.shadow[name] + \
                               (1 - self.decay) * param.data

# 用途: 推理时 EMA 模型通常比最新 checkpoint 好 0.5-2%
# decay 选择: 0.999 (小 batch) ~ 0.9999 (大 batch)
```

## 三、数据增强 (BEV/3D 特有)

### 2D 增强 (在 BEV 中的特殊性)

```python
# ⚠️ BEV 中使用 2D 增强的陷阱:
# 如果只用相机数据做 BEV → 2D 增强直接可用
# 如果融合 LiDAR → 2D 增强需要考虑 3D 一致性

transforms:
  # 安全: 不影响 3D 几何关系
  - ColorJitter(brightness=0.3, contrast=0.3, saturation=0.3, hue=0.1)
  - RandomGaussianNoise(mean=0, std=0.01)
  
  # 谨慎: 会改变相机内参关系
  - RandomResizeCrop: 需同步调整相机内参矩阵
  
  # 禁止: 破坏多相机一致性
  - 逐相机独立 flip (除非所有相机同时左右翻转)
```

### 3D 增强

```python
class BEV3DAugmentation:
    """BEV 感知的 3D 空间增强"""
    
    def __init__(self):
        # 全局旋转: 绕 Z 轴 (垂直轴) 随机旋转
        self.global_rotation = RandomRotation3D(
            angle_range=[-22.5, 22.5],  # 度
            axis='z'
        )
        # 全局缩放
        self.global_scaling = RandomScaling3D(
            scale_range=[0.95, 1.05]
        )
        # 全局平移
        self.global_translation = RandomTranslation3D(
            std=[0.5, 0.5, 0.1]  # x, y, z (米)
        )
        # 随机水平翻转 (镜像世界)
        self.flip = RandomFlip3D(
            prob=0.5,
            direction='horizontal'  # 左右翻转
        )

# 关键: 对点云和 3D box 标签同步变换
```

### GT-Aug (Copy-Paste)

```python
# 从其他场景 Copy 3D objects → Paste 到当前场景
# 模拟复杂交通场景，增加小目标密度

class GT_Augmentation:
    def __call__(self, scene):
        # 1. 从 database 随机采样 N 个 object (含点云 + 标注)
        objects = sample_from_database(n=5)
        
        # 2. 对每个 object:
        for obj in objects:
            # 放置到当前场景的可行区域 (路面)
            obj = place_on_ground(obj, scene.bev_map)
            
            # 碰撞检测: 不与已有 object 重叠
            if not check_collision(obj, scene.existing_objects):
                scene.add_object(obj)
        
        return scene

# 效果: 提升小目标和长尾类别的检测精度
# 使用时注意: TTA 时需要关掉 GT-Aug
```

### Camera Dropout

```python
# 训练时随机丢弃某些相机视角
# → 模型学会利用多视角冗余信息

class CameraDropout:
    def __init__(self, drop_prob=0.1):
        self.drop_prob = drop_prob
    
    def __call__(self, images):
        mask = torch.rand(len(images)) > self.drop_prob
        images[~mask] = 0  # 将丢弃的相机图像置零
        return images, mask

# 效果: 对某个相机故障/遮挡更鲁棒
```

## 四、训练技巧

### 常用 Tricks 速查

| Trick | 作用 | 典型值 | 使用场景 |
|-------|------|--------|----------|
| **Label Smoothing** | 防止过拟合 | ε=0.1 | 分类任务 |
| **DropPath** | ViT/Swin 正则化 | 0.1-0.2 | Transformer |
| **Gradient Clipping** | 防止梯度爆炸 | max_norm=1.0 | 所有训练 |
| **SyncBN** | 跨 GPU BN stats | — | 小 batch 训练 |
| **Weight Decay** | L2 正则化 | 0.01-0.1 | AdamW |
| **Warmup** | 稳定训练初期 | 500-2000 steps | 所有训练 |
| **SWA** | 模型权重平均 | — | 最终提升 |

### 预训练策略

```
ImageNet Pretrain → 自动驾驶微调:
  1. 加载 ImageNet pretrained backbone
  2. 冻结 backbone 前几层 (通用特征)
  3. 只训练 FPN / Neck / Head
  4. 1-2 epochs 后解冻全部参数
  5. 用 1/10 的 LR fine-tune backbone

自监督预训练 (MAE/BEiT):
  - 在大量驾驶数据 (未标注) 上做 masked image modeling
  - 学习到驾驶场景的时序/空间表征
  - 比 ImageNet pretrain 在下游任务好 3-5%
```

### 知识蒸馏

```python
# BEV 蒸馏: 大教师模型 → 小学生模型

class BEVDistillation:
    def __init__(self, teacher, student):
        self.teacher = teacher.eval()  # 冻结
        self.student = student
    
    def distil_loss(self, x):
        with torch.no_grad():
            t_bev = self.teacher(x)['bev_feature']  # [B, C, H, W]
        s_bev = self.student(x)['bev_feature']      # [B, C', H, W]
        
        # Option 1: L2 蒸馏
        loss = F.mse_loss(proj(s_bev), t_bev)
        
        # Option 2: Attention 蒸馏 (蒸馏 attention map)
        # loss = KL(t_attn || s_attn)
        
        # Option 3: Detection head 蒸馏 (更轻量)
        # loss = KL(t_det_logits || s_det_logits)
        
        return loss
```

### FLOPs vs 显存 换算

```
模型复杂度速查:
  FLOPs: 一次前向所需的浮点运算次数
  参数量: 模型文件大小 (影响加载速度)
  推理延迟: 端到端推理时间 (影响实时性)
  
  典型换算 (A100, FP16):
    100M FLOPs ≈ 0.1ms (理论)
    实际: ~30% 理论峰值 (受内存带宽限制)
    
  显存: 参数量 × precision × batch_size + 激活值
    68M params × FP16 × bs=1 ≈ 136MB (参数)
    激活值: ~200-1000MB (取决于输入分辨率)
```

## 六、常见 Debug 流程

### 训练不收敛排查

```
1. 小数据集过拟合测试 (100 samples)
   → 确认模型有学习能力

2. Loss 曲线分析:
   - Loss 一开始就高且不降 → LR 太小 或 初始化问题
   - Loss 快速下降到 NaN → LR 太大, gradient explode
   - Loss 缓慢下降后震荡 → LR schedule 需要调整
   - Loss 下降但 val 不降 → 过拟合

3. 梯度检查:
   - 打印 gradient norm (每层的 L2 范数)
   - 正常范围: 0.01 ~ 10
   - 如果 > 100 → gradient clipping 需要更小 max_norm
   - 如果 < 1e-4 → vanishing gradient, 检查初始化和网络结构

4. 数据检查:
   - 可视化几个 batch 的输入和标签
   - 检查归一化是否正确 (range 检查)
   - 查看数据分布 (类别平衡, 位置分布)
```

### 显存 OOM 排查

```python
# 模块化排查显存

import torch

def check_memory():
    print(f"Allocated: {torch.cuda.memory_allocated()/1024**3:.2f} GB")
    print(f"Cached: {torch.cuda.memory_reserved()/1024**3:.2f} GB")

# 逐步排查:
check_memory()
x = batch['img'].cuda()          # Step 1: 输入
check_memory()
feat = backbone(x)                # Step 2: Backbone
check_memory()
bev_feat = bev_encoder(feat)      # Step 3: BEV Encoder
check_memory()
loss = head(bev_feat)             # Step 4: Head + Loss
check_memory()
loss.backward()                   # Step 5: Backward (最吃显存!)
check_memory()

# 常见显存炸弹:
# - 激活值 (backward 时释放)
# - 时序多帧 (每帧都有激活值 → gradient checkpoint)
# - 大 resolution 特征图
```
