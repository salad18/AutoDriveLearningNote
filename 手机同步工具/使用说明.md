# 手机同步工具说明

把知识库同步到手机 **Obsidian** 的固定流程，已固化成脚本，日常使用只需三步。

## 文件说明

| 文件 | 作用 |
|------|------|
| `同步到手机.bat` | **日常使用入口**，双击即可运行 |
| `sync-to-phone.ps1` | 实际同步脚本（增量复制 + 自动校验 + 写日志 `sync.log`） |
| `使用说明.md` | 本说明 |

## 日常刷新（每次想同步时）

1. 手机插 USB 数据线，通知栏把 USB 模式选为 **「文件传输 (MTP)」**（弹出授权点允许）
2. 电脑双击 `同步到手机.bat`，等窗口显示「校验通过」
3. 完成。**注意**：同步前先在手机上**退出 Obsidian**（避免文件被占用），同步完再打开

> 手机上 Obsidian 打开这个库的位置：**内部共享存储空间 → Obsidian → MyKB**
> （首次打开时选「打开文件夹作为 vault」，并授权「允许管理所有文件」）

## 它做了什么

- **增量同步**：只复制电脑端新增或变化的文件（**按文件大小判断**，MTP 上报的修改时间不可靠），不是全量覆盖
- **先删后拷**：需要更新的文件会先在手机端删除再重新复制，避免 MTP 覆盖文件不可靠
- **自动校验**：同步后逐个检查电脑端文件在手机端是否存在、大小是否一致
- **自动日志**：每次运行记录到 `sync.log`（该日志不会同步到手机）
- **自动建目录**：手机端没有 `Obsidian/MyKB` 时会自动创建（首次使用也能直接跑）
- 跳过：`.git`、`.sync-tmp*` 临时目录、`*.log`、`workspace.json`（桌面端布局配置）、系统垃圾文件

## 常见问题

| 现象 | 处理 |
|------|------|
| 提示「未检测到手机」 | 检查数据线/接口，确认手机 USB 模式是**文件传输**而不是「仅充电」；换一个 USB 口试试 |
| 校验有缺失/失败 | 看窗口里列出的文件名，重新跑一次；仍失败说明该文件被占用（比如 Obsidian 正在打开它），关闭 Obsidian 再试 |
| 内容改了但大小没变 | 极少见，脚本按大小判断不会识别。手动在手机端删掉该文件再同步一次即可 |
| 手机端多出旧文件 | 脚本只增不删（安全考虑）。重命名/删掉的旧笔记不会自动清理，可手动删，或用文件管理器清理 `Obsidian/MyKB` |
| 手机端 `.obsidian` 被误删/损坏 | 不用管，下次同步会自动从电脑端完整重建 |
| 双击 bat 窗口一闪而过 | 用右键 → 编辑，确认内容没被改坏；或直接在 PowerShell 里运行 `sync-to-phone.ps1` |

## 备注

- 同步期间电脑端 Obsidian 可以开着（md 文件可读），但建议同步时不要编辑笔记，避免复制到半截版本
- 知识库在手机端的位置固定为 `Obsidian/MyKB`，不要手动改名，否则脚本会另建一份
- 日志 `sync.log` 已加入 `.gitignore`，不会污染 git 仓库
